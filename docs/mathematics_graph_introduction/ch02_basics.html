第 2 章 グラフの定義と基本用語

本章では、グラフの正確な定義と、以降の章で繰り返し使う基本用語を導入する。グラフ理論は用語が多いが、ほとんどは図を見れば意味が分かる自然なものである。定義を一つずつ図と対応させながら読み進めてほしい。

グラフの定義

定義 2.1（グラフ）

空でない有限集合 \(V\) と、\(V\) の異なる 2 要素からなる部分集合の集合 \(E\) の組 \(G = (V, E)\) をグラフという。\(V\) の要素を頂点、\(E\) の要素を辺という。

頂点はノードや節点、辺はエッジや枝と呼ばれることもある。グラフ \(G\) の頂点集合と辺集合を明示したいときは \(V(G)\), \(E(G)\) と書く。頂点数を \(n = |V|\)、辺数を \(m = |E|\) で表す。

頂点 \(u\) と \(v\) を結ぶ辺 \(\{u, v\}\) を、簡単に \(uv\) と書く。\(uv\) と \(vu\) は同じ辺である。辺 \(uv\) があるとき、\(u\) と \(v\) は隣接しているといい、\(u\) と \(v\) をその辺の端点という。また、辺 \(uv\) は頂点 \(u\) および \(v\) に接続しているという。頂点 \(v\) に隣接する頂点全体の集合を近傍といい、\(N(v)\) と書く。

図 2 に例を示す。このグラフは \(V = \{1, 2, 3, 4, 5\}\)、\(E = \{12, 13, 23, 34, 45\}\) であり、\(n = 5\), \(m = 5\) である。頂点 3 の近傍は \(N(3) = \{1, 2, 4\}\) である。

グラフの図では、頂点の位置や辺の長さ・曲がり方に意味はない。同じグラフをまったく異なる見た目の図で描くこともできる。重要なのは、どの頂点の組が辺で結ばれているかだけである。

多重辺・自己ループと単純グラフ

定義 2.1 のグラフでは、同じ 2 頂点を結ぶ辺は高々 1 本であり、頂点とそれ自身を結ぶ辺はない。応用によってはこれらを許したい場合がある。

  • 同じ 2 頂点を結ぶ複数の辺を多重辺という。

  • 両端が同じ頂点である辺を自己ループ（または単にループ）という。

多重辺や自己ループを許すグラフを多重グラフといい、どちらも持たないグラフを単純グラフという。第 1 章のケーニヒスベルクの橋のグラフは、陸地 A と C を結ぶ橋が 2 本あるので多重グラフである。本書では、特に断らない限りグラフは単純グラフとする。

有向グラフと重み付きグラフ

辺に向きがあるグラフを有向グラフという。有向グラフの辺は頂点の順序対 \((u, v)\) で表し、\(u\) から \(v\) への有向辺（または弧）という。\(u\) を始点、\(v\) を終点という。一方通行の道路、Web ページのリンク、タスク間の依存関係などは有向グラフで表す。有向グラフと区別するため、これまでのグラフを無向グラフともいう。

各辺に数値を対応させたグラフを重み付きグラフという。辺 \(e\) に対応する数値を辺の重みといい、\(w(e)\) と書く。重みは、道路の長さ、通信の遅延、回線の容量、コストなど、応用によってさまざまな意味を持つ。

次数

定義 2.2（次数）

無向グラフの頂点 \(v\) に接続する辺の本数を \(v\) の次数といい、\(\deg(v)\) と書く。多重グラフでは、自己ループは次数に 2 だけ寄与するものとする。

単純グラフでは \(\deg(v) = |N(v)|\) である。次数 0 の頂点を孤立点、次数 1 の頂点を葉という。グラフ \(G\) の頂点の次数の最小値を \(\delta(G)\)、最大値を \(\Delta(G)\) と書く。図 2 のグラフでは、\(\deg(1) = \deg(2) = 2\)、\(\deg(3) = 3\)、\(\deg(4) = 2\)、\(\deg(5) = 1\) であり、\(\delta(G) = 1\)、\(\Delta(G) = 3\) である。

次数を大きい順に並べた列を次数列という。このグラフの次数列は \((3, 2, 2, 2, 1)\) である。

有向グラフでは、頂点 \(v\) を終点とする辺の本数を入次数 \(\deg^-(v)\)、始点とする辺の本数を出次数 \(\deg^+(v)\) という。

握手補題

次数について最も基本的な定理が次の握手補題である。

定理 2.1（握手補題）

任意の無向グラフ \(G = (V, E)\) について、次式が成り立つ。

\[\sum_{v \in V} \deg(v) = 2m\]

証明：各辺 \(uv\) は、\(u\) の次数と \(v\) の次数にそれぞれ 1 ずつ寄与する。したがって次数の総和では、各辺がちょうど 2 回ずつ数えられる。自己ループは定義により次数に 2 寄与するので、多重グラフでも同じ等式が成り立つ。□

名前は「パーティーの参加者が握手した回数を全員分足すと、握手の総数の 2 倍になる」という言い換えに由来する。図 2 のグラフでは、次数の総和は \(2 + 2 + 3 + 2 + 1 = 10 = 2 \times 5\) である。

握手補題から、次の系がすぐに得られる。

系 2.2

任意の無向グラフにおいて、次数が奇数の頂点の個数は偶数である。

証明：次数が偶数の頂点の次数の和は偶数である。全体の和 \(2m\) も偶数なので、次数が奇数の頂点の次数の和も偶数でなければならない。奇数をいくつか足して偶数になるのは、足す個数が偶数のときに限る。□

たとえば「5 人のグループで、全員がちょうど 3 人と知り合いである」という状況はありえない。次数 3 の頂点が 5 個（奇数個）になってしまうからである。

有向グラフでは、各辺がちょうど 1 つの頂点の出次数と、ちょうど 1 つの頂点の入次数に寄与するので、次式が成り立つ。

\[\sum_{v \in V} \deg^+(v) = \sum_{v \in V} \deg^-(v) = m\]

次数列の実現可能性

非負整数の列が与えられたとき、それを次数列とする単純グラフが存在するかを考える。系 2.2 より、総和が奇数の列は実現できない。しかし総和が偶数であっても実現できるとは限らない。たとえば \((3, 3, 3, 1)\) は総和が 10 で偶数だが、頂点数 4 の単純グラフで次数 3 の頂点は他の 3 頂点すべてと隣接するので、次数 3 の頂点が 3 個あれば残りの 1 頂点の次数も 3 になってしまう。

単純グラフの次数列として実現できる列をグラフ的数列という。列がグラフ的数列であるかどうかは、次のハヴェル・ハキミの定理（Havel–Hakimi theorem）を繰り返し使って判定できる。

定理 2.3（ハヴェル・ハキミの定理）

\(d_1 \ge d_2 \ge \cdots \ge d_n\) を非負整数の列とする。この列がグラフ的数列であるための必要十分条件は、先頭の \(d_1\) を取り除き、続く \(d_1\) 個の要素からそれぞれ 1 を引いた列 \((d_2 - 1, \ldots, d_{d_1 + 1} - 1, d_{d_1 + 2}, \ldots, d_n)\) がグラフ的数列であることである（\(d_1 > n - 1\) ならグラフ的数列ではない）。

次数最大の頂点を、次数が大きい順に \(d_1\) 個の頂点と結ぶと考えればよい。得られた列は大きい順に並べ直してから、再び定理を適用する。\((3, 3, 3, 1)\) に適用すると \((2, 2, 0)\) になり、さらに適用すると \((1, -1)\) となって負の値が現れるので、グラフ的数列ではないと分かる。

部分グラフ

定義 2.3（部分グラフ）

グラフ \(H\) と \(G\) が \(V(H) \subseteq V(G)\) かつ \(E(H) \subseteq E(G)\) を満たすとき、\(H\) を \(G\) の部分グラフという。

部分グラフのうち、特に重要なものが 2 つある。

  • \(V(H) = V(G)\) である部分グラフ、つまり頂点をすべて残して辺の一部だけを選んだものを全域部分グラフという。第 6 章の全域木はその代表例である。

  • 頂点の部分集合 \(S \subseteq V(G)\) を選び、\(S\) の 2 頂点を結ぶ \(G\) の辺をすべて残したものを、\(S\) による誘導部分グラフといい、\(G[S]\) と書く。

頂点 \(v\) とそれに接続する辺をすべて除いたグラフを \(G - v\)、辺 \(e\) だけを除いたグラフを \(G - e\) と書く。\(G - v\) は \(G[V \setminus \{v\}]\) に等しい。

グラフの同型

図 6 の 2 つのグラフは、見た目は異なるが、頂点の名前を適切に付け替えると同じグラフになる。このような関係を同型という。

定義 2.4（同型）

グラフ \(G\) と \(H\) について、全単射 \(f : V(G) \to V(H)\) で、任意の \(u, v \in V(G)\) に対して「\(uv \in E(G)\) と \(f(u)f(v) \in E(H)\) が同値」となるものが存在するとき、\(G\) と \(H\) は同型であるといい、\(G \cong H\) と書く。このような \(f\) を同型写像という。

同型なグラフは、頂点の名前が違うだけで構造は同じなので、グラフ理論では同一視することが多い。頂点数、辺数、次数列のように、同型なグラフで必ず等しくなる量をグラフ不変量という。グラフ不変量が一致しなければ同型ではないと結論できる。しかし逆は成り立たない。たとえば、6 頂点の閉路と、2 つの三角形を並べたグラフは、どちらも頂点数 6、辺数 6、次数列 \((2, 2, 2, 2, 2, 2)\) であるが、前者は連結で後者は連結でないので同型ではない（連結の定義は第 4 章で述べる）。

2 つのグラフが同型かどうかを判定する効率的なアルゴリズムが存在するかは、長年の未解決問題である。実用上は、多くのグラフを高速に判定できるアルゴリズムが知られており、NetworkX でも利用できる。

1import networkx as nx
2
3c6 = nx.cycle_graph(6)  # 6 頂点の閉路
4two_triangles = nx.disjoint_union(nx.cycle_graph(3), nx.cycle_graph(3))
5print(sorted(d for _, d in c6.degree()) == sorted(d for _, d in two_triangles.degree()))  # True
6print(nx.is_isomorphic(c6, two_triangles))  # False

まとめ

  • グラフ \(G = (V, E)\) は頂点集合と辺集合の組である。本書では特に断らない限り単純グラフを扱う。

  • 辺に向きがあるものを有向グラフ、辺に数値を対応させたものを重み付きグラフという。

  • 握手補題により、次数の総和は辺数の 2 倍であり、次数が奇数の頂点は偶数個である。

  • 部分グラフのうち、全域部分グラフと誘導部分グラフが特に重要である。

  • 同型なグラフは同じ構造を持つ。グラフ不変量が異なれば同型ではないが、一致しても同型とは限らない。
