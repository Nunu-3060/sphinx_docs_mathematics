第 5 章 グラフ理論入門

鉄道の路線図、コンピュータネットワーク、SNS の友人関係、モジュールの依存関係などは、いずれも「もの」と「もの同士のつながり」で表せる。このような構造を抽象化したものがグラフである。グラフは第 11 章のマルコフ連鎖の状態遷移を表す道具にもなる。本章では、グラフの基本的な用語と性質、および最も基本的な探索アルゴリズムである幅優先探索を学ぶ。

グラフの定義

無向グラフ

頂点の集合 \(V\) と、2 つの頂点を結ぶ辺の集合 \(E\) の組 \(G = (V, E)\) をグラフという。辺に向きがないグラフを無向グラフといい、頂点 \(u, v\) を結ぶ辺を \(\{u, v\}\) と書く。辺 \(\{u, v\}\) があるとき、\(u\) と \(v\) は隣接しているという。

同じ頂点の組を結ぶ辺が複数あるとき、それらを多重辺という。また、ある頂点からそれ自身に戻る辺を自己ループという。多重辺も自己ループも持たないグラフを単純グラフという。本書では、特に断らない限りグラフは有限（頂点も辺も有限個）とする。

有向グラフと重み付きグラフ

辺に向きがあるグラフを有向グラフといい、\(u\) から \(v\) への辺を \((u, v)\) と書く。一方通行の道路や、タスクの依存関係、Web ページのリンクなどは有向グラフで表される。また、各辺に数値（距離、コスト、確率など）を割り当てたグラフを重み付きグラフという。第 11 章で扱うマルコフ連鎖の状態遷移図は、辺に遷移確率を割り当てた重み付き有向グラフである。

次数と握手補題

無向グラフで、頂点 \(v\) に接続する辺の本数を \(v\) の次数といい、\(\deg(v)\) と書く（自己ループは 2 本と数える）。図 5 の無向グラフ \(G\) では、\(\deg(A) = 2\)、\(\deg(B) = 3\)、\(\deg(F) = 1\) である。

定理（握手補題）：任意の無向グラフ \(G = (V, E)\) について

\[\sum_{v \in V} \deg(v) = 2 |E|\]

が成り立つ。

証明：各辺 \(\{u, v\}\) は、\(u\) の次数と \(v\) の次数にそれぞれ 1 ずつ寄与する。したがって、次数の総和では各辺がちょうど 2 回数えられる。

この結果から、次数が奇数の頂点の個数は必ず偶数であることが分かる（次数の総和が偶数なので）。この定理の名前は、パーティーで握手した回数を全員分足すと、握手の総数の 2 倍になることに由来する。これを握手補題という。

道と連結性

頂点の列 \(v_0, v_1, \ldots, v_k\) で、隣り合う頂点がすべて辺で結ばれているものを、\(v_0\) から \(v_k\) への歩道といい、\(k\) をその長さという。頂点に重複のない歩道を道、\(v_0 = v_k\) で、それ以外の頂点に重複のない長さ 3 以上の歩道を閉路という。

任意の 2 頂点の間に道があるグラフを連結であるという。頂点 \(u\) から \(v\) への道のうち、長さが最小のものを最短路といい、その長さを \(u\) と \(v\) の距離という。

木

連結で閉路を持たない無向グラフを木という。木は、ファイルシステムのディレクトリ構造、構文木、探索木など、情報科学のいたるところに現れる。頂点数 \(n\) の無向グラフについて、次の条件は互いに同値である。

  • 木である（連結で閉路を持たない）。

  • 連結で、辺の本数が \(n - 1\) である。

  • 閉路を持たず、辺の本数が \(n - 1\) である。

  • 任意の 2 頂点の間に道がただ 1 つ存在する。

連結グラフ \(G\) のすべての頂点を含み、\(G\) の辺の一部からなる木を、\(G\) の全域木という。全域木は「すべての地点を最小限の配線でつなぐ」といった問題に現れる。

オイラー路

グラフのすべての辺をちょうど 1 回ずつ通る歩道をオイラー路という。同じ頂点は何度通ってもよい。始点と終点が一致するオイラー路をオイラー閉路という。

グラフ理論の起源とされるのが、18 世紀のケーニヒスベルク（現在のカリーニングラード）の橋の問題である。市内を流れる川に 7 本の橋が架かっており、「すべての橋をちょうど 1 回ずつ渡って散歩できるか」が問われた。オイラーは、陸地を頂点、橋を辺とする多重グラフ（図 6）を考え、これが不可能であることを示した。

定理（オイラー）：辺を持つ連結な無向グラフについて、

  • オイラー閉路が存在するための必要十分条件は、すべての頂点の次数が偶数であることである。

  • オイラー路が存在するための必要十分条件は、次数が奇数の頂点が 0 個または 2 個であることである。

必要性は次のように分かる。オイラー路の途中で頂点を通過するたびに、「入る辺」と「出る辺」を 1 本ずつ使う。したがって、始点と終点以外の頂点の次数は偶数でなければならない。ケーニヒスベルクのグラフでは 4 つの頂点すべての次数が奇数なので、オイラー路は存在しない。

二部グラフ

頂点集合を 2 つの集合 \(V_1, V_2\) に分割し、すべての辺が \(V_1\) の頂点と \(V_2\) の頂点を結ぶようにできるグラフを二部グラフという。たとえば「応募者」と「求人」を頂点とし、応募可能な組を辺で結んだグラフは二部グラフである。

定理：グラフが二部グラフであるための必要十分条件は、長さが奇数の閉路を持たないことである。

二部グラフであることは、隣接する頂点を異なる 2 色で塗り分けられることと同じである。長さ 3 の閉路（三角形）は 2 色で塗り分けられないので、二部グラフではない。

グラフの表現

グラフをプログラムで扱うには、主に次の 2 つの表現を使う。頂点を \(1, \ldots, n\) と番号付けたとする。

  • 隣接行列：\(n \times n\) 行列 \(A\) で、頂点 \(i\) と \(j\) が隣接していれば \(A_{ij} = 1\)、そうでなければ \(A_{ij} = 0\) とする。無向グラフでは対称行列になる。2 頂点が隣接しているかを定数時間で判定できるが、\(n^2\) に比例するメモリを使う。

  • 隣接リスト：各頂点について、隣接する頂点のリストを持つ。メモリは頂点数と辺の本数の和に比例し、辺の少ないグラフに向いている。

隣接行列には、\(A^k\) の \((i, j)\) 成分が「頂点 \(i\) から \(j\) への長さ \(k\) の歩道の個数」に等しいという性質がある。この性質は、第 11 章で遷移行列のべき乗が「\(n\) ステップ後の遷移確率」を表すことと対応している。

幅優先探索

辺に重みがないグラフで、ある頂点 \(s\) から各頂点への最短路を求めるには幅優先探索（BFS：breadth-first search）を使う。幅優先探索では、\(s\) から距離 0 の頂点、距離 1 の頂点、距離 2 の頂点、……の順に、キュー（先入れ先出しの待ち行列）を使って頂点を訪問する。

  1. \(s\) の距離を 0 とし、\(s\) をキューに入れる。

  2. キューが空でない間、次を繰り返す。

    1. キューの先頭から頂点 \(u\) を取り出す。

    2. \(u\) に隣接する頂点 \(w\) のうち、まだ距離が決まっていないものについて、距離を「\(u\) の距離 + 1」とし、\(w\) をキューに入れる。

各頂点と各辺を定数回ずつしか調べないので、計算量は頂点数と辺の本数の和に比例する。幅優先探索を少し変更すると、二部グラフの判定（隣接する頂点に交互に色を付けていき、矛盾が生じないかを調べる）や連結性の判定もできる。

Python で確かめる

サンプルコード：ch05_graphs.py

サンプルコードでは、多重辺を許す無向グラフを dict[str, list[str]] の隣接リストで表す。辺 \(\{u, v\}\) を追加するたびに、\(u\) のリストに \(v\) を、\(v\) のリストに \(u\) を追加する。

 1class Graph:
 2    """無向グラフ（多重辺を許す）を隣接リストで表すクラス。"""
 3
 4    def __init__(self, edges: list[tuple[str, str]]) -> None:
 5        self.adjacency: dict[str, list[str]] = {}
 6        for u, v in edges:
 7            self.adjacency.setdefault(u, []).append(v)
 8            self.adjacency.setdefault(v, []).append(u)
 9        self.edge_count = len(edges)
10
11    def vertices(self) -> list[str]:
12        """頂点の一覧を返す。"""
13        return sorted(self.adjacency)
14
15    def degree(self, v: str) -> int:
16        """頂点 v の次数を返す。"""
17        return len(self.adjacency[v])

幅優先探索は collections.deque をキューとして使って実装する。

 1def bfs_distances(self, start: str) -> dict[str, int]:
 2    """幅優先探索で start から各頂点への最短距離（辺の本数）を求める。"""
 3    distances = {start: 0}
 4    queue = deque([start])
 5    while queue:
 6        u = queue.popleft()
 7        for w in self.adjacency[u]:
 8            if w not in distances:
 9                distances[w] = distances[u] + 1
10                queue.append(w)
11    return distances

二部グラフの判定とオイラー路の存在判定は次のとおりである。

 1def is_bipartite(self) -> bool:
 2    """幅優先探索で隣接する頂点を異なる色に塗り分けられるかを調べる（連結グラフを仮定）。"""
 3    start = self.vertices()[0]
 4    color = {start: 0}
 5    queue = deque([start])
 6    while queue:
 7        u = queue.popleft()
 8        for w in self.adjacency[u]:
 9            if w not in color:
10                color[w] = 1 - color[u]
11                queue.append(w)
12            elif color[w] == color[u]:
13                return False
14    return True
15
16def has_euler_path(self) -> bool:
17    """オイラー路が存在するか（連結かつ奇数次数の頂点が 0 個または 2 個か）を返す。"""
18    odd = sum(1 for v in self.vertices() if self.degree(v) % 2 == 1)
19    return self.is_connected() and odd in (0, 2)

--- 幅優先探索 ---

グラフ \(G\) は次数が奇数の頂点が B、C、E、F の 4 個あるので、オイラー路を持たない。

まとめ

  • グラフは頂点と辺の組であり、無向グラフ・有向グラフ・重み付きグラフがある。

  • 握手補題により、次数の総和は辺の本数の 2 倍に等しい。

  • 木は連結で閉路を持たないグラフであり、頂点数 \(n\) の木の辺の本数は \(n - 1\) である。

  • 連結グラフがオイラー路を持つための必要十分条件は、次数が奇数の頂点が 0 個または 2 個であることである。

  • 二部グラフは、奇数長の閉路を持たないグラフであり、2 色で塗り分けられる。

  • 重みのないグラフの最短路は、幅優先探索で頂点数と辺の本数の和に比例する時間で求められる。

グラフ理論をさらに学ぶには [Rosen2019] や [Diestel2017] を参照するとよい。
