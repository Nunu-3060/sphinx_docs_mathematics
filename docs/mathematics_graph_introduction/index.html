グラフ理論入門

本書は、Python などのプログラミングの知識を持つエンジニアや工学系の大学生を対象とした、グラフ理論の入門書である。グラフの基本的な概念から、木・彩色・マッチングといった構造の理論、探索・最短経路・ネットワークフローなどのアルゴリズム、さらに行列を用いた解析やネットワーク科学までを扱う。定義と定理を図で直観的に説明し、主要なアルゴリズムは Python で実装して動作を確かめる。
