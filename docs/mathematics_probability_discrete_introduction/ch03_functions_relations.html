第 3 章 写像と関係

プログラムの関数は、入力を受け取って出力を 1 つ返す。数学でこれに対応する概念が写像である。また、「等しい」「以下である」「割り切る」のように 2 つのものの間に成り立つ性質は、関係として統一的に扱える。本章では写像と関係を学び、第 4 章の数え上げで使う「全単射による個数の比較」を準備する。

写像

写像の定義

集合 \(A\) の各要素 \(a\) に対して、集合 \(B\) の要素をちょうど 1 つ対応させる規則 \(f\) を、\(A\) から \(B\) への写像といい、\(f\colon A \to B\) と書く。\(a\) に対応する要素を \(f(a)\) と書き、\(a\) の像という。\(A\) を定義域、\(B\) を終域という。また、\(f(A) = \{f(a) \mid a \in A\}\) を \(f\) の値域という。値域は終域の部分集合であるが、一般には終域と一致しない。

本書では、終域が数の集合である写像を関数とも呼ぶ。

単射・全射・全単射

写像 \(f\colon A \to B\) について、次の性質を定める。

  • 単射：\(a \ne a'\) ならば \(f(a) \ne f(a')\)。すなわち、異なる要素は異なる要素に移る。

  • 全射：任意の \(b \in B\) に対して \(f(a) = b\) となる \(a \in A\) が存在する。すなわち、値域が終域に一致する。

  • 全単射：単射かつ全射である。

図 3 に、それぞれの例を示す。

有限集合 \(A, B\) について、次が成り立つ。

  • 単射 \(f\colon A \to B\) が存在するならば \(|A| \le |B|\)

  • 全射 \(f\colon A \to B\) が存在するならば \(|A| \ge |B|\)

  • 全単射 \(f\colon A \to B\) が存在するならば \(|A| = |B|\)

最後の性質は、数え上げで非常に役立つ。数えにくい集合 \(A\) があっても、数えやすい集合 \(B\) との全単射を作れれば \(|A| = |B|\) として数えられる。第 2 章で見た「部分集合と \(n\) ビットの整数の対応」は、まさにこの考え方である。また、1 つ目の性質の対偶「\(|A| > |B|\) ならば単射は存在しない」は、第 4 章で扱う鳩の巣原理そのものである。

合成写像と逆写像

写像 \(f\colon A \to B\) と \(g\colon B \to C\) に対して、\((g \circ f)(a) = g(f(a))\) で定まる写像 \(g \circ f\colon A \to C\) を合成写像という。プログラムでいえば、関数の呼び出しを入れ子にすることに当たる。

\(f\) が全単射のとき、各 \(b \in B\) に対して \(f(a) = b\) となる \(a\) がただ 1 つ存在する。この \(a\) を \(b\) に対応させる写像を \(f\) の逆写像といい、\(f^{-1}\colon B \to A\) と書く。\(f^{-1} \circ f\) は \(A\) 上の恒等写像（各要素をそれ自身に移す写像）になる。

関係

関係の定義

集合 \(A\) 上の関係 \(R\) とは、直積 \(A \times A\) の部分集合のことである。\((a, b) \in R\) のとき \(a \mathrel{R} b\) と書き、「\(a\) と \(b\) は関係 \(R\) にある」という。たとえば整数の大小関係 \(\le\) は、\(a \le b\) を満たす順序対 \((a, b)\) 全体の集合と考えられる。

関係 \(R\) について、次の性質を考える。

表 6 関係の性質

性質

定義

反射律

すべての \(a \in A\) について \(a \mathrel{R} a\)

対称律

\(a \mathrel{R} b\) ならば \(b \mathrel{R} a\)

反対称律

\(a \mathrel{R} b\) かつ \(b \mathrel{R} a\) ならば \(a = b\)

推移律

\(a \mathrel{R} b\) かつ \(b \mathrel{R} c\) ならば \(a \mathrel{R} c\)

同値関係と同値類

反射律・対称律・推移律を満たす関係を同値関係という。同値関係は「ある観点で同じとみなせる」ことを表す。

代表例は、正の整数 \(m\) を法とする合同関係である。整数 \(a, b\) について、\(a - b\) が \(m\) で割り切れるとき \(a \equiv b \pmod{m}\) と書く。これは「\(m\) で割った余りが等しい」ことと同じであり、同値関係になる。

同値関係 \(\sim\) について、要素 \(a\) と同値な要素全体の集合 \([a] = \{b \in A \mid a \sim b\}\) を \(a\) の同値類という。同値類について、次の性質が成り立つ。

  • 任意の 2 つの同値類は、一致するか互いに素であるかのどちらかである。

  • すべての同値類の和集合は \(A\) に一致する。

つまり、同値関係は集合 \(A\) を互いに素な部分集合に分割する。このような分割を類別という。たとえば、\(\{0, 1, \ldots, 11\}\) を 4 を法とする合同関係で類別すると、余りが 0, 1, 2, 3 の 4 つの同値類に分かれる。ハッシュ表が、ハッシュ値をバケット数で割った余りによってキーを振り分けるのは、この類別の一例である。

半順序

反射律・反対称律・推移律を満たす関係を半順序という。整数の大小関係 \(\le\)、集合の包含関係 \(\subseteq\)、正の整数の整除関係（\(a\) が \(b\) を割り切るとき \(a \mid b\)）はいずれも半順序である。

大小関係 \(\le\) では任意の 2 つの整数を比較できるが、整除関係では 2 と 3 のように比較できない組がある。任意の 2 要素が比較可能な半順序を全順序という。

有限集合上の半順序は、ハッセ図で表すと分かりやすい。ハッセ図では、\(a \mid b\) かつ \(a \ne b\) で、間に他の要素が入らない組だけを線で結び、大きい方を上に描く。図 4 は 12 の約数の整除関係のハッセ図である。

半順序は、依存関係のあるタスクの実行順序（あるタスクは別のタスクの完了後にしか実行できない）を表す際にも現れる。半順序と矛盾しないように全要素を一列に並べることをトポロジカルソートという。

Python で確かめる

サンプルコード：ch03_functions_relations.py

有限集合の間の写像は、Python の dict でそのまま表せる。単射であることは「値に重複がない」こと、全射であることは「値の集合が終域に一致する」ことと同じである。

 1def is_injective(f: dict[X, Y]) -> bool:
 2    """写像 f が単射かどうかを返す（異なる元の像がすべて異なるか）。"""
 3    return len(set(f.values())) == len(f)
 4
 5
 6def is_surjective(f: dict[X, Y], codomain: set[Y]) -> bool:
 7    """写像 f が終域 codomain への全射かどうかを返す。"""
 8    return set(f.values()) == codomain
 9
10
11def compose(g: dict[Y, Z], f: dict[X, Y]) -> dict[X, Z]:
12    """合成写像 g ∘ f を返す。"""
13    return {x: g[f[x]] for x in f}
14
15
16def inverse(f: dict[X, Y]) -> dict[Y, X]:
17    """全単射 f の逆写像を返す。"""
18    if not is_injective(f):
19        raise ValueError("単射でない写像の逆写像は定義できない")
20    return {y: x for x, y in f.items()}

関係は順序対の集合 set[tuple[int, int]] で表せる。推移律の判定では、\((a, b)\) と \((c, d)\) の組で \(b = c\) となるものすべてについて、\((a, d)\) が関係に含まれるかを調べる。

1def is_transitive(r: Relation) -> bool:
2    """推移律: (a, b) ∈ R かつ (b, c) ∈ R ならば (a, c) ∈ R。"""
3    return all((a, d) in r for a, b in r for c, d in r if b == c)

同値類は、まだどの同値類にも属していない要素 \(a\) を選び、\(a\) と関係にある要素を集めることを繰り返して求める。

1def equivalence_classes(r: Relation, elements: set[int]) -> list[set[int]]:
2    """同値関係 r による同値類の一覧を返す。"""
3    classes: list[set[int]] = []
4    for a in sorted(elements):
5        if any(a in c for c in classes):
6            continue
7        classes.append({b for b in elements if (a, b) in r})
8    return classes

写像 g は "a" と "b" を同じ 1 に移すので単射でなく、3 を値にとらないので終域 \(\{1, 2, 3\}\) への全射でもない。4 を法とする合同関係は同値関係であり、\(\{0, \ldots, 11\}\) が 4 つの同値類に分かれる。整除関係は対称律を満たさず、反対称律を満たすので、同値関係ではなく半順序である。

まとめ

  • 写像は、定義域の各要素に終域の要素をちょうど 1 つ対応させる規則である。

  • 単射・全射・全単射の存在は、有限集合の要素数の大小関係と対応する。全単射を作ることは、要素数が等しいことを示す強力な方法である。

  • 関係は直積の部分集合であり、反射律・対称律・推移律を満たすものが同値関係、反射律・反対称律・推移律を満たすものが半順序である。

  • 同値関係は集合を互いに素な同値類に分割する。

写像と関係については [Rosen2019] に詳しい。
