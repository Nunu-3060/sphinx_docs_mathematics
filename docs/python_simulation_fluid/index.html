Python による流体・粒子シミュレーション入門

本書は、Python と NumPy を使って粒子と流体の数値シミュレーションを一から実装しながら、その基礎を学ぶための入門書である。方程式を離散化し、コードにして動かし、結果が正しいかを確かめる、という一連の流れを、小さな動くサンプルコードで体験することを目的とする。
