4. 推論と証明

数学の議論は、正しいと認めた前提から、正しい推論を積み重ねて結論を導く形で進む。本章では、推論が正しいとはどういうことかを論理式で定め、代表的な証明の方法を紹介する。

4.1. 推論の妥当性

いくつかの命題（前提）から別の命題（結論）を導くことを推論という。

定義（妥当な推論）

前提 \(A_1, A_2, \ldots, A_n\) から結論 \(B\) を導く推論が妥当であるとは、論理式 \((A_1 \land A_2 \land \cdots \land A_n) \to B\) が恒真式であることをいう。

言い換えると、前提がすべて真になるどのような場合にも、結論が真になる推論が妥当な推論である。妥当性は推論の形式だけで決まり、前提が実際に真であるかどうかとは関係しない。前提が偽であれば、妥当な推論から偽の結論が導かれることもある。

4.2. 推論規則

妥当な推論のうち、基本的でよく使われるものを推論規則という。代表的な推論規則を次の表に示す。

名称

前提

結論

例

モーダスポネンス

\(P\)、\(P \to Q\)

\(Q\)

雨が降った。雨が降ったら道がぬれる。よって道がぬれる。

モーダストレンス

\(\neg Q\)、\(P \to Q\)

\(\neg P\)

道はぬれていない。雨が降ったら道がぬれる。よって雨は降っていない。

仮言三段論法

\(P \to Q\)、\(Q \to R\)

\(P \to R\)

雨が降ったら道がぬれる。道がぬれたら滑りやすい。よって雨が降ったら滑りやすい。

選言三段論法

\(P \lor Q\)、\(\neg P\)

\(Q\)

バグの原因は設定かコードにある。設定ではない。よってコードにある。

いずれも、前提の論理積から結論への含意が恒真式であることを真理値表で確かめられる。

4.3. 妥当でない推論の例

次の 2 つは妥当に見えて妥当でない推論であり、誤りとしてよく現れる。

名称

前提

結論

反例となる真理値

後件肯定

\(Q\)、\(P \to Q\)

\(P\)

\(P\) が F、\(Q\) が T

前件否定

\(\neg P\)、\(P \to Q\)

\(\neg Q\)

\(P\) が F、\(Q\) が T

「雨が降ったら道がぬれる。道がぬれている。よって雨が降った」は後件肯定である。道は散水でもぬれるので、結論は導けない。後件肯定は、第 3 章で述べた「逆も真」と考える誤りと同じ構造をしている。

推論の妥当性を確かめるサンプルコードは、第 2 章の truth_table.py に含めてある。

4.4. 証明の方法

数学における証明とは、前提や既に正しいと分かっている命題から、妥当な推論を重ねて主張を導くことである。以下、整数に関する例を通して代表的な証明の方法を紹介する。整数 \(n\) が偶数であるとは、ある整数 \(k\) を用いて \(n = 2k\) と書けることをいい、奇数であるとは \(n = 2k + 1\) と書けることをいう。どの整数も偶数か奇数のどちらか一方である。

4.4.1. 直接証明

\(P \to Q\) を示すために、\(P\) を仮定して \(Q\) を導く方法である。

定理

整数 \(n\) が奇数ならば、\(n^2\) は奇数である。

証明 \(n\) が奇数なので、ある整数 \(k\) を用いて \(n = 2k + 1\) と書ける。このとき \(n^2 = 4k^2 + 4k + 1 = 2(2k^2 + 2k) + 1\) であり、\(2k^2 + 2k\) は整数なので \(n^2\) は奇数である。□

4.4.2. 対偶による証明

\(P \to Q\) は対偶 \(\neg Q \to \neg P\) と論理的に同値である。そこで、\(P \to Q\) の代わりに対偶を示してもよい。直接示すのが難しいときに有効である。

定理

整数 \(n\) について、\(n^2\) が偶数ならば、\(n\) は偶数である。

証明 対偶「\(n\) が奇数ならば、\(n^2\) は奇数である」を示せばよい。これは直接証明の項で示した定理そのものである。□

4.4.3. 背理法

\(P\) を示すために、\(\neg P\) を仮定して矛盾を導く方法である。\(\neg P \to \bot\) は \(P\) と論理的に同値なので、この方法で \(P\) が示される。

定理

\(\sqrt{2}\) は無理数である。

証明 \(\sqrt{2}\) が有理数であると仮定する。すると、1 以外に共通の約数を持たない正の整数 \(a\)、\(b\) を用いて \(\sqrt{2} = a / b\) と書ける。両辺を 2 乗して整理すると \(a^2 = 2b^2\) となるので、\(a^2\) は偶数である。対偶による証明の項の定理より \(a\) は偶数なので、整数 \(c\) を用いて \(a = 2c\) と書ける。これを代入すると \(4c^2 = 2b^2\)、すなわち \(b^2 = 2c^2\) となり、同様に \(b\) も偶数である。\(a\) と \(b\) がともに偶数であることは、\(a\) と \(b\) が 1 以外に共通の約数を持たないことに矛盾する。したがって \(\sqrt{2}\) は無理数である。□

4.4.4. 場合分けによる証明

\(P \lor Q\)、\(P \to R\)、\(Q \to R\) がすべて真ならば \(R\) は真である。そこで、起こりうる場合を漏れなく挙げ、それぞれの場合に主張を示す方法がある。

定理

任意の整数 \(n\) について、\(n(n + 1)\) は偶数である。

証明 \(n\) が偶数の場合、\(n = 2k\) と書けるので \(n(n + 1) = 2k(2k + 1)\) は偶数である。\(n\) が奇数の場合、\(n = 2k + 1\) と書けるので \(n(n + 1) = (2k + 1)(2k + 2) = 2(2k + 1)(k + 1)\) は偶数である。いずれの場合も \(n(n + 1)\) は偶数である。□

場合分けでは、挙げた場合が起こりうるすべての場合を尽くしていることを必ず確認する。

4.4.5. 反例

「すべての \(x\) について〇〇である」という形の主張が偽であることを示すには、〇〇でない \(x\) を 1 つ挙げれば十分である。このような \(x\) を反例という。たとえば「すべての素数は奇数である」は、反例 2 があるので偽である。この形の主張の扱いは第 5 章で詳しく述べる。

4.5. 数学的帰納法

自然数 \(n\) に関する主張 \(P(n)\) が、すべての自然数 \(n\) について成り立つことを示したいとする。\(P(n)\) は \(n\) の値ごとに真偽が定まる主張であり、第 5 章で述語として扱う。

数学的帰納法

次の 2 つが示されれば、すべての自然数 \(n\) について \(P(n)\) が成り立つ。

  1. \(P(0)\) が成り立つ（基底段階）。

  2. 任意の自然数 \(n\) について、\(P(n)\) が成り立つならば \(P(n + 1)\) が成り立つ（帰納段階）。

基底段階から \(P(0)\) が、帰納段階を繰り返し適用して \(P(1)\)、\(P(2)\)、… が順に得られる、というのがこの方法の考え方である。帰納段階で仮定する \(P(n)\) を帰納法の仮定という。

定理

任意の自然数 \(n\) について、\(0 + 1 + 2 + \cdots + n = \dfrac{n(n + 1)}{2}\) が成り立つ。

証明 この等式を \(P(n)\) とする。

  • 基底段階：左辺は 0、右辺は \(0 \cdot 1 / 2 = 0\) なので \(P(0)\) は成り立つ。

  • 帰納段階：\(P(n)\) が成り立つと仮定する。このとき

    \[0 + 1 + \cdots + n + (n + 1) = \frac{n(n + 1)}{2} + (n + 1) = \frac{(n + 1)(n + 2)}{2}\]

    となるので \(P(n + 1)\) も成り立つ。

以上より、すべての自然数 \(n\) について \(P(n)\) が成り立つ。□

数学的帰納法は、プログラムのループが正しいことを確かめる考え方と対応している。次の関数を考える。

1def triangular(n: int) -> int:
2    total = 0
3    for i in range(n + 1):
4        total += i
5        # ここで total == i * (i + 1) // 2 が成り立つ
6    return total

コメントの条件のように、ループの各回の終わりで常に成り立つ条件をループ不変条件という。\(i = 0\) の回で成り立つこと（基底段階）と、ある回で成り立てば次の回でも成り立つこと（帰納段階）を示せば、数学的帰納法によりすべての回で成り立つことが分かる。最後の回（\(i = n\)）の終わりで不変条件が成り立つことから、関数の戻り値が \(n(n + 1) / 2\) であることが分かる。
