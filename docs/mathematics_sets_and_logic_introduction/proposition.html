2. 命題と論理演算

本章では、論理の最小単位である命題と、命題どうしを組み合わせる論理演算を導入する。

2.1. 命題

定義（命題）

真であるか偽であるかが定まる主張を命題という。命題が真であるか偽であるかを、その命題の真理値という。

本書では、真理値の真を T、偽を F で表す。次の例を見てみよう。

  • 「2 は素数である」は真の命題である。

  • 「10 は 3 で割り切れる」は偽の命題である。

  • 「このプログラムは速い」は、何をもって速いとするかが決まっていないため命題ではない。

  • 「\(x > 3\)」は、\(x\) の値が決まるまで真偽が定まらないため、このままでは命題ではない。このように変数を含む主張は、第 5 章で述語として扱う。

個々の命題の中身に立ち入らず、命題を記号 \(P\)、\(Q\)、\(R\) などで表して議論することが多い。このような記号を命題変数という。

2.2. 論理演算

既存の命題から新しい命題を作る操作を論理演算といい、論理演算を表す記号を論理記号という。基本的な論理演算は次の 5 つである。

論理和は、両方が真の場合も真になる。日常語の「または」は「どちらか一方だけ」の意味で使われることもあるが、論理和はそうではない。一方だけが真のときに真になる演算は排他的論理和と呼ばれ、\(P \oplus Q\) と書く。

2.4. 含意の真理値

含意 \(P \to Q\) において、\(P\) を前件、\(Q\) を後件という。含意の真理値表で戸惑いやすいのは、前件 \(P\) が偽のとき、後件 \(Q\) の真偽にかかわらず \(P \to Q\) が真になる点である。

これは「約束が破られたかどうか」と考えると納得しやすい。「雨が降ったら試合を中止する」という約束が破られるのは、雨が降ったのに試合を中止しなかった場合だけである。雨が降らなかった場合は、試合を中止しても中止しなくても、約束を破ったことにはならない。含意 \(P \to Q\) が偽になるのも、\(P\) が真で \(Q\) が偽の場合だけである。

また、含意は因果関係を表すものではない。「1 + 1 = 2 ならば、東京は日本の首都である」は、前件と後件に何の関係もないが、どちらも真なので含意としては真である。含意はあくまで真理値だけで決まる演算である。

なお、真理値表から分かるとおり、\(P \to Q\) は \(\neg P \lor Q\) と同じ真理値をとる。

2.5. 論理式と結合の強さ

命題変数と論理記号を組み合わせて作った式を論理式という。たとえば \((P \to Q) \land (Q \to P)\) は論理式である。

括弧を減らすため、論理記号の結合の強さを \(\neg\)、\(\land\)、\(\lor\)、\(\to\)、\(\leftrightarrow\) の順に強いものとする。たとえば \(\neg P \lor Q \land R\) は \((\neg P) \lor (Q \land R)\) を表す。\(\to\) を続けて書く場合など、紛らわしいときは括弧を省略しない。

2.6. Python の論理演算子との対応

Python の bool 型の値 True と False を真理値とみなすと、論理演算は次のように書ける。

論理演算

Python の式

備考

\(\neg P\)

not p

\(P \land Q\)

p and q

\(P \lor Q\)

p or q

\(P \to Q\)

not p or q

含意を表す演算子は無い。bool 型どうしなら p <= q でもよい。

\(P \leftrightarrow Q\)

p == q

\(P \oplus Q\)

p != q

bool 型どうしなら p ^ q でもよい。

p <= q で含意を表せるのは、Python では False < True であり、p <= q が偽になるのは p が True で q が False の場合だけだからである。ただし、意図が読み取りにくいので、実際のコードでは not p or q と書くほうがよい。

Python の論理演算子は、数学の論理演算と次の点で異なる。

短絡評価

and と or は左の被演算子から評価し、結果が確定した時点で右の被演算子を評価しない。これを短絡評価という。真理値の計算結果は数学の論理演算と同じだが、右の被演算子に副作用がある場合や、評価すると例外が発生する場合に違いが現れる。

1def check(name: str, value: bool) -> bool:
2    print(name, "を評価した")
3    return value
4
5
6result = check("左", False) and check("右", True)
7# 「左 を評価した」だけが表示される。左が偽なので、右は評価されない。

この性質は、if x is not None and x.value > 0: のように、前の条件が成り立つときだけ後の条件を評価したい場合に利用される。数学の \(P \land Q\) には評価の順序という概念が無く、\(P \land Q\) と \(Q \land P\) は常に同じ真理値をとる。

被演算子をそのまま返す

and と or の結果は bool 型とは限らず、どちらかの被演算子がそのまま返る。たとえば 0 or "abc" の値は "abc" であり、[] and 1 の値は [] である。Python では 0、空文字列、空のリストなどが偽として扱われる（このような値を falsy という）ためである。論理演算として扱う場合は、被演算子を bool 型にそろえておくとよい。

ビット演算子との混同

&、|、~ はビット演算子であり、論理演算子ではない。bool 型どうしの & と | は論理積・論理和と同じ結果になるが、~True の値は False ではなく -2 になる。bool 型が整数型 int の派生型であり、~ は整数のビット反転として計算されるためである。否定には必ず not を使う。

2.7. サンプルコード

論理式を「真理値を受け取って bool 型の値を返す関数」として表し、真理値表を表示するサンプルコードを示す。第 3 章と第 4 章で扱う恒真式・論理的同値・推論の妥当性の判定もこのファイルに含めた。

truth_table.py

 1"""命題論理の真理値表を作り、恒真式・論理的同値を判定するサンプル。
 2
 3論理式は「命題変数の真理値（bool）を受け取って bool を返す関数」として表す。
 4"""
 5
 6from collections.abc import Callable, Iterator, Sequence
 7from itertools import product
 8
 9# 命題変数の個数は論理式ごとに異なるため、引数の個数は固定しない。
10Formula = Callable[..., bool]
11
12
13def implies(p: bool, q: bool) -> bool:
14    """含意 p → q の真理値を返す。"""
15    return (not p) or q
16
17
18def iff(p: bool, q: bool) -> bool:
19    """同値 p ↔ q の真理値を返す。"""
20    return p == q
21
22
23def assignments(n: int) -> Iterator[tuple[bool, ...]]:
24    """n 個の命題変数への真理値の割り当てを、すべて真の行から順に列挙する。"""
25    return product((True, False), repeat=n)
26
27
28def to_symbol(value: bool) -> str:
29    """真理値を T または F で表す。"""
30    return "T" if value else "F"
31
32
33def print_truth_table(formula: Formula, names: Sequence[str], label: str) -> None:
34    """論理式 formula の真理値表を表示する。"""
35    print(" ".join(names), "|", label)
36    for values in assignments(len(names)):
37        cells = " ".join(to_symbol(v) for v in values)
38        print(cells, "|", to_symbol(formula(*values)))
39
40
41def is_tautology(formula: Formula, n: int) -> bool:
42    """n 変数の論理式 formula が恒真式であるかを判定する。"""
43    return all(formula(*values) for values in assignments(n))
44
45
46def is_satisfiable(formula: Formula, n: int) -> bool:
47    """n 変数の論理式 formula が充足可能であるかを判定する。"""
48    return any(formula(*values) for values in assignments(n))
49
50
51def are_equivalent(f: Formula, g: Formula, n: int) -> bool:
52    """n 変数の論理式 f と g が論理的に同値であるかを判定する。"""
53    return all(f(*values) == g(*values) for values in assignments(n))
54
55
56def main() -> None:
57    print("真理値表: P → Q")
58    print_truth_table(implies, ["P", "Q"], "P → Q")
59    print()
60
61    print("排中律 P ∨ ¬P は恒真式か:", is_tautology(lambda p: p or not p, 1))
62    print("P ∧ ¬P は充足可能か:", is_satisfiable(lambda p: p and not p, 1))
63
64    # ド・モルガンの法則: ¬(P ∧ Q) ≡ ¬P ∨ ¬Q
65    print("ド・モルガンの法則は成り立つか:",
66          are_equivalent(lambda p, q: not (p and q), lambda p, q: (not p) or (not q), 2))
67
68    # 対偶: P → Q ≡ ¬Q → ¬P、逆: P → Q と Q → P は同値でない
69    print("P → Q と対偶 ¬Q → ¬P は同値か:",
70          are_equivalent(implies, lambda p, q: implies(not q, not p), 2))
71    print("P → Q と逆 Q → P は同値か:",
72          are_equivalent(implies, lambda p, q: implies(q, p), 2))
73
74    # 推論の妥当性: (P ∧ (P → Q)) → Q が恒真式ならモーダスポネンスは妥当
75    print("モーダスポネンスは妥当か:",
76          is_tautology(lambda p, q: implies(p and implies(p, q), q), 2))
77    # 後件肯定: (Q ∧ (P → Q)) → P は恒真式でない
78    print("後件肯定は妥当か:",
79          is_tautology(lambda p, q: implies(q and implies(p, q), p), 2))
80
81
82if __name__ == "__main__":
83    main()
