7. 関係

「\(x\) は \(y\) 以下である」「\(x\) と \(y\) は同じ部署に所属する」のように、2 つのものの間に成り立つかどうかが定まる性質を関係という。本章では、関係を集合として定義し、同値関係と順序関係という 2 つの重要な種類を学ぶ。

7.1. 二項関係

定義（二項関係）

直積 \(A \times B\) の部分集合 \(R\) を、\(A\) から \(B\) への二項関係という。\((a, b) \in R\) であることを \(a \, R \, b\) とも書く。\(A \times A\) の部分集合を \(A\) 上の二項関係という。

関係を「成り立つ組の集合」として定義するのがこの定義の要点である。たとえば \(A = \{1, 2, 3\}\) 上の関係 \(\leq\) は、次の順序対の集合として表される。

\[\{(1, 1), (1, 2), (1, 3), (2, 2), (2, 3), (3, 3)\}\]

以下、単に関係といえば二項関係を指す。関係の例を挙げる。

  • 自然数全体 \(\mathbb{N}\) 上の \(\leq\) と \(<\)

  • 任意の集合上の等号 \(=\)

  • 正の整数全体上の整除関係 \(\mid\)。\(a \mid b\) は「\(a\) は \(b\) を割り切る」、すなわち \(b\) が \(a\) の倍数であることを表す。

  • 整数全体 \(\mathbb{Z}\) 上の合同関係。\(a \equiv b \pmod{3}\) は、\(a - b\) が 3 で割り切れることを表す。

Python では、有限集合上の関係を tuple 型の値の集合として表せる。リレーショナルデータベースのテーブルや、SNS のフォロー関係（\(a\) が \(b\) をフォローしている）も、組の集合として表される関係の例である。

7.2. 関係の性質

集合 \(A\) 上の関係 \(R\) について、次の性質を考える。

名称

定義

反射律

\(\forall a \, (a \, R \, a)\)

対称律

\(\forall a \, \forall b \, (a \, R \, b \to b \, R \, a)\)

\(\forall a \, \forall b \, \forall c \, ((a \, R \, b \land b \, R \, c) \to a \, R \, c)\)

7.3. 同値関係

定義（同値関係）

反射律・対称律・推移律を満たす関係を同値関係という。

同値関係は「ある観点で同じとみなせる」という関係を抽象化したものである。等号 \(=\) や合同関係 \(\equiv \pmod{3}\)、「同じ部署に所属する」は同値関係である。

プログラミングでよく現れる同値関係として、ある関数 key を使って「key(x) == key(y) のとき \(x\) と \(y\) を関係付ける」と定めた関係がある。これは等号の性質から必ず同値関係になる。たとえば、文字列を str.lower の結果で比べれば、大文字と小文字を区別しない比較という同値関係が得られる。

定義（同値類・商集合）

\(R\) を集合 \(A\) 上の同値関係とする。\(a \in A\) に対し、\(a\) と関係する要素全体の集合

\[[a] = \{x \in A \mid x \, R \, a\}\]

を \(a\) の同値類という。同値類全体の集合 \(\{[a] \mid a \in A\}\) を \(A\) の \(R\) による商集合といい、\(A / R\) と書く。

たとえば \(\mathbb{Z}\) 上の \(\equiv \pmod{3}\) の同値類は、3 で割った余りが 0、1、2 の整数全体の 3 つである。

\[\begin{split}[0] &= \{\ldots, -3, 0, 3, 6, \ldots\} \\ [1] &= \{\ldots, -2, 1, 4, 7, \ldots\} \\ [2] &= \{\ldots, -1, 2, 5, 8, \ldots\}\end{split}\]

\([0] = [3] = [6]\) のように、同じ同値類を異なる要素で表せることに注意する。同値類から選んだ要素を代表元という。

同値類には次の重要な性質がある。

定理

\(R\) を集合 \(A\) 上の同値関係とする。任意の \(a, b \in A\) について、\([a] = [b]\) と \([a] \cap [b] = \emptyset\) のどちらか一方が成り立つ。

証明 \([a] \cap [b] \neq \emptyset\) と仮定して \([a] = [b]\) を示す。\(c \in [a] \cap [b]\) とすると \(c \, R \, a\) かつ \(c \, R \, b\) である。対称律より \(a \, R \, c\) なので、推移律より \(a \, R \, b\) である。対称律よりさらに \(b \, R \, a\) も成り立つ。ここで \(x \in [a]\) とすると \(x \, R \, a\) と \(a \, R \, b\) から推移律により \(x \, R \, b\)、すなわち \(x \in [b]\) である。よって \([a] \subseteq [b]\) である。\(a\) と \(b\) の役割を入れ替えれば \([b] \subseteq [a]\) も同様に示せるので、\([a] = [b]\) である。□

また、反射律より \(a \in [a]\) なので、どの要素もいずれかの同値類に属し、同値類は空でない。つまり、同値類は集合 \(A\) を、互いに重ならない空でない部分集合に切り分ける。このような切り分けを \(A\) の分割という。

定義（分割）

集合 \(A\) の空でない部分集合からなる集合族 \(\mathcal{F}\) が次の 2 つを満たすとき、\(\mathcal{F}\) を \(A\) の分割という。

  1. \(\mathcal{F}\) の要素の和集合が \(A\) に等しい。

  2. \(\mathcal{F}\) の異なる 2 つの要素は互いに素である。

逆に、集合 \(A\) の分割が与えられたとき、「同じ部分集合に属する」という関係は同値関係になる。したがって、集合上の同値関係と分割は一対一に対応する。次の図は、集合 \(\{0, 1, \ldots, 8\}\) を \(\equiv \pmod{3}\) で分割した様子を示している。

同値類による分割は、データを key 関数の値ごとにグループ化する処理（itertools.groupby や SQL の GROUP BY）と同じ構造をしている。

7.4. 順序関係

定義（半順序・全順序）

反射律・反対称律・推移律を満たす関係を半順序という。半順序 \(\preceq\) が定められた集合を半順序集合という。半順序 \(\preceq\) がさらに

\[\forall a \, \forall b \, (a \preceq b \lor b \preceq a)\]

を満たすとき、\(\preceq\) を全順序という。

全順序では任意の 2 つの要素が比較できるが、半順序では比較できない要素の組があってもよい。

  • 実数全体 \(\mathbb{R}\) 上の \(\leq\) は全順序である。

  • 正の整数全体上の整除関係 \(\mid\) は半順序だが全順序ではない。\(2 \mid 3\) も \(3 \mid 2\) も成り立たない。

  • 集合 \(A\) のべき集合 \(\mathcal{P}(A)\) 上の包含関係 \(\subseteq\) は半順序である。\(A\) が 2 個以上の要素を持てば全順序ではない。たとえば \(\{a\}\) と \(\{b\}\) は比較できない。

ソフトウェアのモジュール間の依存関係や、タスクの前後関係も半順序で表されることが多い。有限の半順序集合の要素は、半順序と矛盾しないように一列に並べられる。この並べ方を求めることをトポロジカルソートといい、ビルドツールやパッケージ管理ツールで使われている。Python では標準ライブラリの graphlib.TopologicalSorter で計算できる。

7.5. ハッセ図

有限の半順序集合は、ハッセ図で図示できる。ハッセ図では、要素を点で表し、\(a \preceq b\) かつ \(a \neq b\) で、その間に別の要素が入らないとき、\(a\) を下、\(b\) を上に置いて線で結ぶ。反射律と推移律から分かる線は省略する。

次の図は、12 の正の約数全体 \(\{1, 2, 3, 4, 6, 12\}\) の整除関係と、\(\mathcal{P}(\{a, b, c\})\) の包含関係のハッセ図である。

たとえば 1 つ目の図で \(1 \mid 4\) は線で直接結ばれていないが、\(1 \mid 2\) と \(2 \mid 4\) から推移律で分かる。

7.6. 関係の合成と推移閉包

定義（関係の合成）

\(R\) を \(A\) から \(B\) への関係、\(S\) を \(B\) から \(C\) への関係とする。\(A\) から \(C\) への関係

\[S \circ R = \{(a, c) \in A \times C \mid \exists b \in B \, (a \, R \, b \land b \, S \, c)\}\]

を \(R\) と \(S\) の合成という。

\(S \circ R\) は「\(R\) をたどってから \(S\) をたどる」関係である。\(R\) を先に書かないのは、第 8 章で扱う合成写像の記法に合わせるためである。

「直接依存している」という関係 \(R\) があるとき、「直接または間接に依存している」という関係は、\(R\)、\(R \circ R\)、\(R \circ R \circ R\)、… の和集合になる。これは \(R\) を含む推移的な関係のうち最小のものであり、\(R\) の推移閉包という。推移閉包は、ネットワークの到達可能性や、パッケージの間接的な依存関係を求める際に現れる。

7.7. サンプルコード

有限集合上の関係の性質を判定し、同値類と推移閉包を求めるサンプルコードを示す。推移閉包は、合成によって新しい組が増えなくなるまで組を追加して求めている。

relation.py

 1"""有限集合上の二項関係の性質を判定し、同値類と推移閉包を求めるサンプル。
 2
 3集合 A 上の二項関係 R は、A × A の部分集合（順序対の集合）として表す。
 4"""
 5
 6from collections.abc import Callable, Iterable
 7from typing import TypeVar
 8
 9T = TypeVar("T")
10Relation = set[tuple[T, T]]
11
12
13def relation_from(a: Iterable[T], predicate: Callable[[T, T], bool]) -> Relation[T]:
14    """集合 a 上で predicate(x, y) が真になる順序対 (x, y) の集合を返す。"""
15    elements = list(a)
16    return {(x, y) for x in elements for y in elements if predicate(x, y)}
17
18
19def is_reflexive(a: set[T], r: Relation[T]) -> bool:
20    """反射律: すべての x について x R x。"""
21    return all((x, x) in r for x in a)
22
23
24def is_symmetric(r: Relation[T]) -> bool:
25    """対称律: x R y ならば y R x。"""
26    return all((y, x) in r for x, y in r)
27
28
29def is_antisymmetric(r: Relation[T]) -> bool:
30    """反対称律: x R y かつ y R x ならば x = y。"""
31    return all(x == y for x, y in r if (y, x) in r)
32
33
34def is_transitive(r: Relation[T]) -> bool:
35    """推移律: x R y かつ y R z ならば x R z。"""
36    return all((x, z) in r for x, y in r for y2, z in r if y == y2)
37
38
39def is_equivalence(a: set[T], r: Relation[T]) -> bool:
40    """同値関係（反射律・対称律・推移律）であるかを判定する。"""
41    return is_reflexive(a, r) and is_symmetric(r) and is_transitive(r)
42
43
44def is_partial_order(a: set[T], r: Relation[T]) -> bool:
45    """半順序（反射律・反対称律・推移律）であるかを判定する。"""
46    return is_reflexive(a, r) and is_antisymmetric(r) and is_transitive(r)
47
48
49def equivalence_classes(a: set[T], r: Relation[T]) -> set[frozenset[T]]:
50    """同値関係 r による a の同値類全体（商集合）を返す。"""
51    return {frozenset(y for y in a if (x, y) in r) for x in a}
52
53
54def compose(s: Relation[T], r: Relation[T]) -> Relation[T]:
55    """合成 S ∘ R = {(x, z) | ある y について x R y かつ y S z} を返す。"""
56    return {(x, z) for x, y in r for y2, z in s if y == y2}
57
58
59def transitive_closure(r: Relation[T]) -> Relation[T]:
60    """推移閉包（r を含む最小の推移的な関係）を返す。
61
62    合成で得られる順序対を、新しい順序対が増えなくなるまで追加する。
63    """
64    closure = set(r)
65    while True:
66        extended = closure | compose(r, closure)
67        if extended == closure:
68            return closure
69        closure = extended
70
71
72def main() -> None:
73    a = set(range(9))
74    mod3 = relation_from(a, lambda x, y: (x - y) % 3 == 0)
75    print("x ≡ y (mod 3) は同値関係か:", is_equivalence(a, mod3))
76    for cls in sorted(equivalence_classes(a, mod3), key=min):
77        print("  同値類:", sorted(cls))
78
79    divisors = {1, 2, 3, 4, 6, 12}
80    divides = relation_from(divisors, lambda x, y: y % x == 0)
81    print("整除関係は半順序か:", is_partial_order(divisors, divides))
82    print("整除関係は同値関係か:", is_equivalence(divisors, divides))
83
84    # 直接の依存関係から、間接的なものを含む依存関係を求める。
85    depends = {("app", "web"), ("web", "http"), ("http", "socket"), ("app", "db")}
86    for x, y in sorted(transitive_closure(depends)):
87        mark = "" if (x, y) in depends else "（間接）"
88        print(f"  {x} は {y} に依存する{mark}")
89
90
91if __name__ == "__main__":
92    main()
