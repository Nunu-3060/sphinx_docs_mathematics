第 7 章 確率変数と期待値

第 6 章では事象の確率を扱った。しかし実際に知りたいのは「サイコロの目の和」「アルゴリズムの比較回数」「待ち時間」のように、試行の結果によって決まる数値であることが多い。本章では、試行の結果に数値を対応させる確率変数を導入し、その平均的な値である期待値と、ばらつきの大きさを表す分散を学ぶ。特に、期待値の線形性と指示確率変数を組み合わせる技法は、第 12 章のアルゴリズム解析で中心的な役割を果たす。

確率変数

離散確率空間 \((\Omega, P)\) において、各根元事象 \(\omega \in \Omega\) に実数 \(X(\omega)\) を対応させる写像 \(X\colon \Omega \to \mathbb{R}\) を確率変数という。本書の標本空間は有限または可算なので、確率変数のとる値も有限個または可算個であり、このような確率変数を離散確率変数という。

例：2 個のサイコロを投げる試行で \(\Omega = \{1, \ldots, 6\}^2\) とし、根元事象 \(\omega = (a, b)\) に目の和 \(S(\omega) = a + b\) を対応させると、\(S\) は 2 から 12 までの値をとる確率変数である。

確率変数 \(X\) が値 \(x\) をとるという事象 \(\{\omega \in \Omega \mid X(\omega) = x\}\) を、\(\{X = x\}\) と略記する。その確率は \(P(X = x)\) と書く。同様に、\(P(X \le x)\) や \(P(a \le X \le b)\) などの記法も用いる。

確率質量関数と累積分布関数

離散確率変数 \(X\) のとりうる値の集合を \(\{x_1, x_2, \ldots\}\) とする。各値 \(x_i\) に確率 \(P(X = x_i)\) を対応させる関数

\[p_X(x) = P(X = x)\]

を \(X\) の確率質量関数という。確率質量関数は \(p_X(x) \ge 0\) と \(\sum_i p_X(x_i) = 1\) を満たす。確率変数の値と確率の対応関係を、確率変数の分布（確率分布）という。

また、実数 \(x\) に対して

\[F_X(x) = P(X \le x) = \sum_{x_i \le x} p_X(x_i)\]

で定まる関数を \(X\) の累積分布関数という。離散確率変数の累積分布関数は、各値 \(x_i\) で \(p_X(x_i)\) だけ跳ね上がる階段状の関数である。累積分布関数は単調非減少であり、\(x \to -\infty\) で 0、\(x \to \infty\) で 1 に近づく。また、\(P(a < X \le b) = F_X(b) - F_X(a)\) が成り立つ。

期待値

定義

離散確率変数 \(X\) の期待値を次で定める。

\[E[X] = \sum_{i} x_i \, P(X = x_i)\]

期待値は、とりうる値をその確率で重み付けした平均である。試行を何度も繰り返したときの \(X\) の値の平均は \(E[X]\) に近づく（第 10 章の大数の法則）。\(X\) が可算無限個の値をとる場合は、右辺の級数が絶対収束するとき（\(\sum_i |x_i| P(X = x_i) < \infty\) のとき）に限って期待値が存在するという。本書で扱う確率変数の期待値はすべて存在する。

根元事象ごとに足し合わせると、同じ値が次のように書ける。

\[E[X] = \sum_{\omega \in \Omega} X(\omega) \, p(\omega)\]

右辺の和を \(X(\omega)\) の値ごとにまとめると定義の式になるので、両者は等しい。

例：サイコロ 1 個の目 \(X\) の期待値は \(E[X] = (1 + 2 + \cdots + 6)/6 = 7/2\) である。期待値 \(7/2\) は \(X\) がとりうる値ではない。期待値は「最も出やすい値」ではなく、あくまで重み付き平均である。

確率変数の関数の期待値

関数 \(g\) に対して \(g(X)\) も確率変数であり、その期待値は \(g(X)\) の分布を求めなくても、\(X\) の分布から次のように計算できる。

\[E[g(X)] = \sum_{i} g(x_i) \, P(X = x_i)\]

たとえば \(E[X^2] = \sum_i x_i^2 \, P(X = x_i)\) である。一般に \(E[g(X)] \ne g(E[X])\) であることに注意する。たとえばサイコロの目 \(X\) では、\(E[X^2] = 91/6\) であるが、\((E[X])^2 = 49/4\) である。

期待値の線形性

定理（期待値の線形性）：確率変数 \(X, Y\) と定数 \(a, b, c\) について

\[E[aX + bY + c] = a E[X] + b E[Y] + c\]

が成り立つ。

証明：根元事象ごとの和の表示を使うと

\[E[aX + bY + c] = \sum_{\omega} (a X(\omega) + b Y(\omega) + c) \, p(\omega) = a \sum_{\omega} X(\omega) p(\omega) + b \sum_{\omega} Y(\omega) p(\omega) + c \sum_{\omega} p(\omega)\]

であり、\(\sum_\omega p(\omega) = 1\) より結論が得られる。

この定理で重要なのは、\(X\) と \(Y\) が独立である必要がない点である。確率変数がどのように依存し合っていても、和の期待値は期待値の和になる。帰納法により、\(n\) 個の確率変数についても \(E[X_1 + \cdots + X_n] = E[X_1] + \cdots + E[X_n]\) が成り立つ。

例：2 個のサイコロの目の和 \(S = X_1 + X_2\) の期待値は、\(S\) の分布を求めなくても \(E[S] = E[X_1] + E[X_2] = 7/2 + 7/2 = 7\) と分かる。

指示確率変数

事象 \(A\) に対して、\(A\) が起これば 1、起こらなければ 0 をとる確率変数

\[\begin{split}I_A(\omega) = \begin{cases} 1 & (\omega \in A) \\ 0 & (\omega \notin A) \end{cases}\end{split}\]

を \(A\) の指示確率変数という。指示確率変数の期待値は、事象の確率に等しい。

\[E[I_A] = 1 \cdot P(A) + 0 \cdot P(\overline{A}) = P(A)\]

「何かが起こる回数」は、指示確率変数の和として表せる。これと期待値の線形性を組み合わせると、回数の分布を求めなくても期待値を簡単に計算できる。

例 1：サイコロを 3 回投げて 6 が出る回数 \(X\) の期待値を求める。\(A_i\) を「\(i\) 回目に 6 が出る」とすると \(X = I_{A_1} + I_{A_2} + I_{A_3}\) なので、\(E[X] = 3 \times (1/6) = 1/2\) である。

例 2（順列の不動点）：\(1, \ldots, n\) をランダムに並べ替えたとき（\(n!\) 通りの順列が同様に確からしいとする）、自分の位置に来る数の個数 \(X\) の期待値を求める。\(A_i\) を「数 \(i\) が \(i\) 番目の位置に来る」とすると、\(P(A_i) = (n - 1)!/n! = 1/n\) である。\(X = \sum_{i=1}^{n} I_{A_i}\) なので

\[E[X] = \sum_{i=1}^{n} P(A_i) = n \times \frac{1}{n} = 1\]

となる。\(n\) がいくつであっても、平均してちょうど 1 個の数が自分の位置に来る。\(A_i\) 同士は独立でない（たとえば \(n - 1\) 個が自分の位置に来れば、残りの 1 個も必ず自分の位置に来る）が、期待値の線形性は独立性を必要としないので、この計算は正しい。なお、\(P(X = 0)\) は第 4 章の攪乱順列の割合 \(D(n)/n!\) であり、\(1/e\) に近づく。

分散と標準偏差

期待値が同じでも、値のばらつき方は確率変数によって異なる。\(\mu = E[X]\) とするとき、ばらつきの大きさを表す量として、\(X\) の分散を次で定める。

\[V[X] = E[(X - \mu)^2]\]

分散の正の平方根 \(\sigma = \sqrt{V[X]}\) を標準偏差という。標準偏差は \(X\) と同じ単位を持つので、ばらつきの大きさを直感的に把握しやすい。

期待値の線形性を使って展開すると、計算に便利な次の公式が得られる。

\[V[X] = E[X^2 - 2\mu X + \mu^2] = E[X^2] - 2\mu E[X] + \mu^2 = E[X^2] - (E[X])^2\]

また、定数 \(a, b\) について \(V[aX + b] = a^2 V[X]\) が成り立つ。定数 \(b\) を加えても分布が平行移動するだけでばらつきは変わらず、\(a\) 倍するとばらつきは \(|a|\) 倍（分散は \(a^2\) 倍）になる。

例：サイコロ 1 個の目 \(X\) について、\(E[X^2] = (1 + 4 + 9 + 16 + 25 + 36)/6 = 91/6\) なので

\[V[X] = \frac{91}{6} - \left(\frac{7}{2}\right)^2 = \frac{35}{12} \approx 2.92, \qquad \sigma = \sqrt{35/12} \approx 1.71\]

である。

期待値と異なり、分散は一般に線形ではない。\(V[X + Y] = V[X] + V[Y]\) は \(X\) と \(Y\) が独立な場合などに限って成り立つ。この点は第 9 章で共分散を導入して詳しく扱う。

Python で確かめる

サンプルコード：ch07_random_variables.py

サンプルコードでは、離散確率変数の分布を「値 → 確率」の辞書 dict[int, Fraction] で表す。同様に確からしい根元事象の一覧と、根元事象から値を計算する関数（確率変数）を受け取り、分布を作る。

1def distribution_of(outcomes: Iterable[T], variable: Callable[[T], int]) -> Distribution:
2    """同様に確からしい根元事象の一覧と確率変数から、確率変数の分布を作る。"""
3    counts: dict[int, int] = {}
4    total = 0
5    for w in outcomes:
6        x = variable(w)
7        counts[x] = counts.get(x, 0) + 1
8        total += 1
9    return {x: Fraction(c, total) for x, c in sorted(counts.items())}

期待値・分散・累積分布関数は、定義どおりに実装できる。expectation の引数 g を指定すると、\(E[g(X)]\) を計算する。

 1def expectation(dist: Distribution, g: Callable[[int], Fraction | int] = lambda x: x) -> Fraction:
 2    """g(X) の期待値 E[g(X)] = Σ g(x) P(X = x) を返す。"""
 3    return sum((Fraction(g(x)) * p for x, p in dist.items()), Fraction(0))
 4
 5
 6def variance(dist: Distribution) -> Fraction:
 7    """分散 V[X] = E[X^2] - (E[X])^2 を返す。"""
 8    mean = expectation(dist)
 9    return expectation(dist, lambda x: x * x) - mean * mean
10
11
12def cdf(dist: Distribution, x: int) -> Fraction:
13    """累積分布関数 F(x) = P(X <= x) を返す。"""
14    return sum((p for v, p in dist.items() if v <= x), Fraction(0))

不動点の個数の期待値は、全列挙でもすべての \(n\) で 1 になっている。また、2 個のサイコロの目の和 \(S\) の分散 \(35/6\) は、1 個の分散 \(35/12\) のちょうど 2 倍である。これは 2 個のサイコロの目が独立であるためで、第 9 章で理由を説明する。なお、不動点の個数の分散も \(n \ge 2\) で 1 になっている。この事実も第 9 章の共分散を使うと導ける。

まとめ

  • 確率変数は根元事象に実数を対応させる写像であり、その分布は確率質量関数または累積分布関数で表される。

  • 期待値 \(E[X] = \sum_i x_i P(X = x_i)\) は値の重み付き平均である。

  • 期待値の線形性 \(E[X + Y] = E[X] + E[Y]\) は、確率変数が独立でなくても成り立つ。

  • 回数は指示確率変数の和で表せる。指示確率変数の期待値は事象の確率に等しいので、回数の期待値は確率の和で求められる。

  • 分散 \(V[X] = E[X^2] - (E[X])^2\) はばらつきの大きさを表し、\(V[aX + b] = a^2 V[X]\) を満たす。

確率変数と期待値については [Ross2019] に詳しい。指示確率変数を使った計算の例は [Mitzenmacher2017] に多く収められている。
