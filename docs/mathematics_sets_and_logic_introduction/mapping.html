8. 写像

写像は、集合の要素に別の集合の要素を対応させる規則である。プログラミングの関数とよく似ているが、異なる点もある。本章では、写像を関係の特別な場合として定義し、その基本的な性質を学ぶ。

8.1. 写像の定義

定義（写像）

集合 \(A\) から集合 \(B\) への関係 \(f \subseteq A \times B\) が

\[\forall a \in A \, \exists! \, b \in B \, ((a, b) \in f)\]

を満たすとき、\(f\) を \(A\) から \(B\) への写像といい、\(f \colon A \to B\) と書く。\((a, b) \in f\) であることを \(f(a) = b\) と書き、\(b\) を \(f\) による \(a\) の像という。\(A\) を \(f\) の定義域、\(B\) を \(f\) の終域という。

ここで \(\exists! \, b\) は「条件を満たす \(b\) がただ 1 つ存在する」ことを表す。つまり写像の条件は、次の 2 つからなる。

  • 定義域のどの要素にも、対応する終域の要素がある。

  • 対応する終域の要素は 1 つに限られる。

たとえば、\(f(x) = x^2\) で定まる \(f \colon \mathbb{R} \to \mathbb{R}\) は写像である。一方、\(\{(x, y) \in \mathbb{R} \times \mathbb{R} \mid x = y^2\}\) は \(\mathbb{R}\) から \(\mathbb{R}\) への写像ではない。\(x = 1\) には \(y = 1\) と \(y = -1\) の 2 つが対応し、\(x = -1\) には対応する \(y\) が無いからである。

写像 \(f\) が要素 \(a\) を \(f(a)\) に対応させることを \(a \mapsto f(a)\) とも書く。また、2 つの写像 \(f, g \colon A \to B\) が等しいとは、すべての \(a \in A\) について \(f(a) = g(a)\) であることをいう。写像は対応の結果だけで決まり、計算の手順は問わない。

8.2. Python の関数との違い

写像と Python の関数はよく似ているが、次の点で異なる。

  • Python の関数は、例外を送出したり、終了しなかったりすることがある。そのような引数では値が定まらないので、写像の条件の 1 つ目を満たさない。

  • Python の関数は、乱数や現在時刻、外部の状態によって、同じ引数に対して異なる値を返すことがある。これは写像の条件の 2 つ目を満たさない。

  • Python の関数は、画面への出力やファイルの書き込みのような副作用を持つことがある。写像には対応以外の働きは無い。

したがって、写像に近いのは、どの引数に対しても必ず終了して値を返し、同じ引数に同じ値を返し、副作用を持たない関数である。このような関数は純粋関数とも呼ばれる。

有限集合の間の写像は、定義域の要素をキーとする辞書（dict 型）で表すのが分かりやすい。辞書のキーは重複しないので、キーの集合が定義域に一致していれば写像の条件を満たす。

8.3. 像と逆像

定義（像・逆像）

写像 \(f \colon A \to B\) について、\(X \subseteq A\) と \(Y \subseteq B\) に対し

\[\begin{split}f(X) &= \{f(x) \mid x \in X\} \\ f^{-1}(Y) &= \{a \in A \mid f(a) \in Y\}\end{split}\]

と定め、\(f(X)\) を \(X\) の像、\(f^{-1}(Y)\) を \(Y\) の逆像という。

\(f(A)\) を \(f\) の像という。\(f(A)\) を値域と呼ぶ文献もあるが、値域という語は終域の意味で使われることもあるため、本書では使わない。

たとえば \(f \colon \mathbb{Z} \to \mathbb{Z}\)、\(f(x) = x^2\) について、

  • \(f(\{-1, 0, 1\}) = \{0, 1\}\)

  • \(f^{-1}(\{4\}) = \{-2, 2\}\)

  • \(f^{-1}(\{3\}) = \emptyset\)

である。逆像は、後述の逆写像が存在しない写像に対しても定義される。たとえばデータベースの検索は「属性の値がある範囲に入るレコード全体」を求める操作なので、逆像を求める操作とみなせる。

像と逆像は、集合演算と次の関係にある。

\[\begin{split}f(X_1 \cup X_2) &= f(X_1) \cup f(X_2) \\ f(X_1 \cap X_2) &\subseteq f(X_1) \cap f(X_2) \\ f^{-1}(Y_1 \cup Y_2) &= f^{-1}(Y_1) \cup f^{-1}(Y_2) \\ f^{-1}(Y_1 \cap Y_2) &= f^{-1}(Y_1) \cap f^{-1}(Y_2)\end{split}\]

2 行目だけは等号が成り立つとは限らない。上の \(f(x) = x^2\) で \(X_1 = \{-1\}\)、\(X_2 = \{1\}\) とすると、\(f(X_1 \cap X_2) = f(\emptyset) = \emptyset\) だが、\(f(X_1) \cap f(X_2) = \{1\}\) である。

8.4. 単射・全射・全単射

定義（単射・全射・全単射）

写像 \(f \colon A \to B\) について、

  • \(\forall a \in A \, \forall a' \in A \, (f(a) = f(a') \to a = a')\) が成り立つとき、\(f\) を単射という。

  • \(\forall b \in B \, \exists a \in A \, (f(a) = b)\) が成り立つとき、\(f\) を全射という。

  • 単射かつ全射であるとき、\(f\) を全単射という。

単射の条件は、対偶をとると「\(a \neq a'\) ならば \(f(a) \neq f(a')\)」となる。つまり単射とは、異なる要素が異なる要素に移る写像である。全射の条件は \(f(A) = B\)、すなわち終域のどの要素も何かの像になっていることである。全単射は、定義域と終域の要素を過不足なく一対一に対応させる写像である。

同じ式で定まる写像でも、定義域と終域によって性質が変わる。たとえば \(f(x) = x^2\) は、\(f \colon \mathbb{Z} \to \mathbb{Z}\) としては単射でも全射でもないが、\(f \colon \mathbb{N} \to \mathbb{N}\) としては単射になる。写像を考えるときは、常に定義域と終域を明示する必要がある。

これらの概念はプログラミングにも現れる。データの符号化（エンコード）は、元のデータを復元（デコード）できるように単射でなければならない。一方、ハッシュ関数は、入力となりうる値の数が出力の値の数より多いので、単射にはなりえない。これは第 9 章の鳩の巣原理から分かる。

8.5. 合成写像

定義（合成写像）

写像 \(f \colon A \to B\) と \(g \colon B \to C\) に対し、\(a \mapsto g(f(a))\) で定まる写像 \(A \to C\) を \(f\) と \(g\) の合成写像といい、\(g \circ f\) と書く。

\(g \circ f\) は「\(f\) を先に、\(g\) を後に適用する」写像である。記号の並び順と適用の順が逆になるのは、\((g \circ f)(a) = g(f(a))\) と書いたときに \(g\) と \(f\) の並び順がそろうようにするためである。

写像の合成は結合法則 \(h \circ (g \circ f) = (h \circ g) \circ f\) を満たす。一方、交換法則は一般に成り立たない。\(f(x) = x + 1\) と \(g(x) = 2x\) について、\((g \circ f)(x) = 2x + 2\) だが \((f \circ g)(x) = 2x + 1\) である。

また、単射どうしの合成は単射、全射どうしの合成は全射、したがって全単射どうしの合成は全単射である。

8.6. 逆写像

集合 \(A\) の各要素をそれ自身に対応させる写像を \(A\) 上の恒等写像といい、\(\mathrm{id}_A\) と書く。

定義（逆写像）

写像 \(f \colon A \to B\) に対し、写像 \(g \colon B \to A\) が \(g \circ f = \mathrm{id}_A\) と \(f \circ g = \mathrm{id}_B\) を満たすとき、\(g\) を \(f\) の逆写像といい、\(f^{-1}\) と書く。

定理

写像 \(f \colon A \to B\) が逆写像を持つための必要十分条件は、\(f\) が全単射であることである。

証明 \(f\) が逆写像 \(g\) を持つとする。\(f(a) = f(a')\) ならば \(a = g(f(a)) = g(f(a')) = a'\) なので \(f\) は単射である。また、任意の \(b \in B\) について \(f(g(b)) = b\) なので \(f\) は全射である。

逆に \(f\) が全単射であるとする。全射なので、任意の \(b \in B\) に対して \(f(a) = b\) となる \(a \in A\) があり、単射なのでそのような \(a\) はただ 1 つである。この \(a\) を \(g(b)\) と定めると、\(g \colon B \to A\) は写像であり、作り方から \(g \circ f = \mathrm{id}_A\) と \(f \circ g = \mathrm{id}_B\) を満たす。□

たとえば \(f \colon \mathbb{R} \to \mathbb{R}\)、\(f(x) = 2x + 1\) の逆写像は \(f^{-1}(y) = (y - 1) / 2\) である。

逆像の記号 \(f^{-1}(Y)\) と逆写像の記号 \(f^{-1}\) は同じ記号を使うが、別のものである。逆像はどの写像についても定義されるが、逆写像は全単射の場合だけ存在する。\(f\) が全単射のときは、\(\{b\}\) の逆像は逆写像による \(b\) の像を唯一の要素とする集合 \(\{f^{-1}(b)\}\) になるので、混乱は生じない。

8.7. サンプルコード

有限集合の間の写像を辞書で表し、像・逆像・単射・全射・逆写像・合成写像を扱うサンプルコードを示す。

mapping.py

 1"""有限集合間の写像を辞書で表し、単射・全射を判定するサンプル。"""
 2
 3from typing import Generic, TypeVar
 4
 5A = TypeVar("A")
 6B = TypeVar("B")
 7C = TypeVar("C")
 8
 9
10class Mapping(Generic[A, B]):
11    """定義域・終域・対応表の組で表した写像。"""
12
13    def __init__(self, domain: set[A], codomain: set[B], table: dict[A, B]) -> None:
14        # 写像の条件: 定義域のすべての要素に、終域の要素がちょうど 1 つ対応する。
15        # dict のキーは重複しないため、キーの集合が定義域と一致すれば十分である。
16        if set(table) != domain:
17            raise ValueError("対応表のキーが定義域と一致しない")
18        if not set(table.values()) <= codomain:
19            raise ValueError("終域に含まれない値がある")
20        self.domain = domain
21        self.codomain = codomain
22        self.table = table
23
24    def __call__(self, x: A) -> B:
25        return self.table[x]
26
27    def image(self, xs: set[A]) -> set[B]:
28        """部分集合 xs の像 f(xs) を返す。"""
29        return {self.table[x] for x in xs}
30
31    def preimage(self, ys: set[B]) -> set[A]:
32        """部分集合 ys の逆像 f⁻¹(ys) を返す。"""
33        return {x for x in self.domain if self.table[x] in ys}
34
35    def is_injective(self) -> bool:
36        """単射であるか: 異なる要素の像が常に異なる。"""
37        return len(set(self.table.values())) == len(self.domain)
38
39    def is_surjective(self) -> bool:
40        """全射であるか: 像が終域全体に一致する。"""
41        return self.image(self.domain) == self.codomain
42
43    def is_bijective(self) -> bool:
44        """全単射であるか。"""
45        return self.is_injective() and self.is_surjective()
46
47    def inverse(self) -> "Mapping[B, A]":
48        """逆写像を返す。全単射でなければ ValueError を送出する。"""
49        if not self.is_bijective():
50            raise ValueError("全単射でないので逆写像は存在しない")
51        return Mapping(self.codomain, self.domain, {y: x for x, y in self.table.items()})
52
53
54def compose(g: Mapping[B, C], f: Mapping[A, B]) -> Mapping[A, C]:
55    """合成写像 g ∘ f を返す。f の終域と g の定義域が一致していなければならない。"""
56    if f.codomain != g.domain:
57        raise ValueError("f の終域と g の定義域が一致しない")
58    return Mapping(f.domain, g.codomain, {x: g(f(x)) for x in f.domain})
59
60
61def describe(name: str, f: Mapping[A, B]) -> None:
62    print(f"{name}: 単射={f.is_injective()}, 全射={f.is_surjective()}, 全単射={f.is_bijective()}")
63
64
65def main() -> None:
66    a = {-2, -1, 0, 1, 2}
67    square = Mapping(a, {0, 1, 4}, {x: x * x for x in a})
68    describe("f(x) = x²（{-2, ..., 2} → {0, 1, 4}）", square)
69    print("  f({-1, 0, 1}) =", sorted(square.image({-1, 0, 1})))
70    print("  f⁻¹({4}) =", sorted(square.preimage({4})))
71
72    shift = Mapping(a, {-1, 0, 1, 2, 3}, {x: x + 1 for x in a})
73    describe("g(x) = x + 1（{-2, ..., 2} → {-1, ..., 3}）", shift)
74    g_inv = shift.inverse()
75    print("  g⁻¹(3) =", g_inv(3))
76
77    h = compose(square, Mapping(a, a, {x: -x for x in a}))
78    print("(f ∘ (x ↦ -x))(2) =", h(2))
79
80
81if __name__ == "__main__":
82    main()
