3. 論理式の同値変形

見た目の異なる論理式が、常に同じ真理値をとることがある。本章では、そのような論理式どうしの関係を調べ、論理式を変形する規則を整理する。

3.1. 恒真式と矛盾式

定義（恒真式・矛盾式・充足可能）

命題変数の真理値をどのように定めても真になる論理式を恒真式（トートロジー）という。どのように定めても偽になる論理式を矛盾式という。真になる真理値の定め方が少なくとも 1 つある論理式を充足可能であるという。

たとえば \(P \lor \neg P\) は恒真式であり、\(P \land \neg P\) は矛盾式である。\(P \to Q\) は恒真式でも矛盾式でもなく、充足可能である。

以下では、恒真式を代表する定数 \(\top\)、矛盾式を代表する定数 \(\bot\) も論理式として用いる。\(\top\) は常に真、\(\bot\) は常に偽である。

3.2. 論理的同値

定義（論理的同値）

論理式 \(A\) と \(B\) が、命題変数の真理値のどのような定め方に対しても同じ真理値をとるとき、\(A\) と \(B\) は論理的に同値であるといい、\(A \equiv B\) と書く。

\(A \equiv B\) であることは、\(A \leftrightarrow B\) が恒真式であることと同じである。また、\(A \equiv B\) であることは、\(A\) と \(B\) の真理値表を作って最後の列が一致することを確かめれば判定できる。

記号 \(\equiv\) は論理演算ではない点に注意する。\(A \leftrightarrow B\) は真にも偽にもなりうる論理式だが、\(A \equiv B\) は 2 つの論理式の間に成り立つ関係についての主張である。

3.3. 同値法則

よく使われる論理的同値を次の表にまとめる。これらはすべて真理値表で確かめられる。

名称

法則

二重否定

\(\neg \neg P \equiv P\)

交換法則

\(P \land Q \equiv Q \land P\)、\(P \lor Q \equiv Q \lor P\)

結合法則

\((P \land Q) \land R \equiv P \land (Q \land R)\)、\((P \lor Q) \lor R \equiv P \lor (Q \lor R)\)

分配法則

\(P \land (Q \lor R) \equiv (P \land Q) \lor (P \land R)\)、\(P \lor (Q \land R) \equiv (P \lor Q) \land (P \lor R)\)

ド・モルガンの法則

\(\neg (P \land Q) \equiv \neg P \lor \neg Q\)、\(\neg (P \lor Q) \equiv \neg P \land \neg Q\)

べき等法則

\(P \land P \equiv P\)、\(P \lor P \equiv P\)

吸収法則

\(P \land (P \lor Q) \equiv P\)、\(P \lor (P \land Q) \equiv P\)

排中律・矛盾律

\(P \lor \neg P \equiv \top\)、\(P \land \neg P \equiv \bot\)

定数の法則

\(P \land \top \equiv P\)、\(P \lor \bot \equiv P\)、\(P \land \bot \equiv \bot\)、\(P \lor \top \equiv \top\)

含意の書き換え

\(P \to Q \equiv \neg P \lor Q\)

対偶

\(P \to Q \equiv \neg Q \to \neg P\)

同値の書き換え

\(P \leftrightarrow Q \equiv (P \to Q) \land (Q \to P)\)

論理式の一部を、それと論理的に同値な論理式で置き換えても、全体の真理値は変わらない。したがって、同値法則を繰り返し適用して論理式を変形できる。たとえば、含意の否定は次のように変形できる。

\[ \begin{aligned} \neg (P \to Q) &\equiv \neg (\neg P \lor Q) && \text{（含意の書き換え）} \\ &\equiv \neg \neg P \land \neg Q && \text{（ド・モルガンの法則）} \\ &\equiv P \land \neg Q && \text{（二重否定）} \end{aligned} \]

つまり「\(P\) ならば \(Q\)」の否定は「\(P\) ならば \(Q\) でない」ではなく、「\(P\) であり、かつ \(Q\) でない」である。

同値変形はプログラムの条件式の整理にも使える。たとえば、次の 2 つの条件式は同じ意味である。

1if not (x < 0 or x > 100):
2    print("範囲内")
3
4if x >= 0 and x <= 100:  # ド・モルガンの法則で否定を内側に移した
5    print("範囲内")

さらに、Python では 2 つ目の条件式を 0 <= x <= 100 と書ける。

3.4. 逆・裏・対偶

含意 \(P \to Q\) に対して、次の 3 つの含意を考える。

名称

論理式

\(P \to Q\) との関係

逆

\(Q \to P\)

論理的に同値とは限らない

裏

\(\neg P \to \neg Q\)

論理的に同値とは限らない

対偶

\(\neg Q \to \neg P\)

論理的に同値である

たとえば、整数 \(x\) についての命題「\(x = 2\) ならば \(x^2 = 4\)」は真である。その対偶「\(x^2 \neq 4\) ならば \(x \neq 2\)」も真である。一方、逆「\(x^2 = 4\) ならば \(x = 2\)」は \(x = -2\) のときに成り立たない。

なお、逆と裏は互いに対偶の関係にあるので、逆と裏は論理的に同値である。「ある命題が真なら、その逆も真」と考えてしまう誤りは日常でもよく見られるので注意する。

3.5. 標準形

論理式は同値変形によってさまざまな形に書き換えられる。そこで、決まった形に書き換えておくと、比較や機械的な処理がしやすくなる。

定義（リテラル・選言標準形・連言標準形）

命題変数またはその否定をリテラルという。リテラルの論理積を、いくつか論理和で結んだ形の論理式を選言標準形という。リテラルの論理和を、いくつか論理積で結んだ形の論理式を連言標準形という。

たとえば \((P \land \neg Q) \lor (\neg P \land Q)\) は選言標準形、\((P \lor Q) \land (\neg P \lor \neg Q)\) は連言標準形である。

任意の論理式は、真理値表から次の手順で選言標準形に書き換えられる。

  1. 真理値表で、論理式が T になる行をすべて選ぶ。

  2. 選んだ行ごとに、その行で T の命題変数はそのまま、F の命題変数は否定をとったリテラルを作り、それらの論理積を作る。この論理積は、その行の真理値の定め方のときだけ T になる。

  3. 作った論理積をすべて論理和で結ぶ。

連言標準形は逆に、論理式が F になる行に注目する。F になる行ごとに、その行でだけ F になるリテラルの論理和を作り、それらをすべて論理積で結べばよい。

例として \(P \leftrightarrow Q\) を考える。T になる行は \((P, Q) = (\mathrm{T}, \mathrm{T}), (\mathrm{F}, \mathrm{F})\) なので、選言標準形は \((P \land Q) \lor (\neg P \land \neg Q)\) である。F になる行は \((\mathrm{T}, \mathrm{F}), (\mathrm{F}, \mathrm{T})\) なので、連言標準形は \((\neg P \lor Q) \land (P \lor \neg Q)\) である。

T になる行が 1 つも無い論理式（矛盾式）の選言標準形は \(\bot\)、F になる行が 1 つも無い論理式（恒真式）の連言標準形は \(\top\) とする。

連言標準形は、与えられた論理式が充足可能かどうかを判定する SAT ソルバーの入力形式として広く使われている。

真理値表から選言標準形と連言標準形を作るサンプルコードを示す。

normal_form.py

 1"""真理値表から選言標準形・連言標準形を作るサンプル。"""
 2
 3from collections.abc import Callable, Sequence
 4from itertools import product
 5
 6Formula = Callable[..., bool]
 7
 8
 9def literal(name: str, positive: bool) -> str:
10    """命題変数 name のリテラル（name または ¬name）を返す。"""
11    return name if positive else "¬" + name
12
13
14def dnf(formula: Formula, names: Sequence[str]) -> str:
15    """formula と同値な選言標準形を返す。
16
17    真になる行ごとに「その行でだけ真になるリテラルの論理積」を作り、それらの論理和をとる。
18    """
19    terms = []
20    for values in product((True, False), repeat=len(names)):
21        if formula(*values):
22            literals = [literal(n, v) for n, v in zip(names, values)]
23            terms.append("(" + " ∧ ".join(literals) + ")")
24    # 真になる行が無ければ、空の論理和すなわち恒偽 ⊥ になる。
25    return " ∨ ".join(terms) if terms else "⊥"
26
27
28def cnf(formula: Formula, names: Sequence[str]) -> str:
29    """formula と同値な連言標準形を返す。
30
31    偽になる行ごとに「その行でだけ偽になるリテラルの論理和」を作り、それらの論理積をとる。
32    """
33    clauses = []
34    for values in product((True, False), repeat=len(names)):
35        if not formula(*values):
36            literals = [literal(n, not v) for n, v in zip(names, values)]
37            clauses.append("(" + " ∨ ".join(literals) + ")")
38    # 偽になる行が無ければ、空の論理積すなわち恒真 ⊤ になる。
39    return " ∧ ".join(clauses) if clauses else "⊤"
40
41
42def main() -> None:
43    examples: list[tuple[str, Formula, list[str]]] = [
44        ("P ↔ Q", lambda p, q: p == q, ["P", "Q"]),
45        ("P ⊕ Q（排他的論理和）", lambda p, q: p != q, ["P", "Q"]),
46        ("(P ∧ Q) ∨ R", lambda p, q, r: (p and q) or r, ["P", "Q", "R"]),
47    ]
48    for label, formula, names in examples:
49        print(label)
50        print("  選言標準形:", dnf(formula, names))
51        print("  連言標準形:", cnf(formula, names))
52
53
54if __name__ == "__main__":
55    main()

実行結果は次のとおりである。

P ↔ Q
  選言標準形: (P ∧ Q) ∨ (¬P ∧ ¬Q)
  連言標準形: (¬P ∨ Q) ∧ (P ∨ ¬Q)
P ⊕ Q（排他的論理和）
  選言標準形: (P ∧ ¬Q) ∨ (¬P ∧ Q)
  連言標準形: (¬P ∨ ¬Q) ∧ (P ∨ Q)
(P ∧ Q) ∨ R
  選言標準形: (P ∧ Q ∧ R) ∨ (P ∧ Q ∧ ¬R) ∨ (P ∧ ¬Q ∧ R) ∨ (¬P ∧ Q ∧ R) ∨ (¬P ∧ ¬Q ∧ R)
  連言標準形: (¬P ∨ Q ∨ R) ∧ (P ∨ ¬Q ∨ R) ∧ (P ∨ Q ∨ R)

この方法で得られる標準形は最も短いものとは限らない。たとえば \((P \land Q) \lor R\) 自体も選言標準形である。

3.6. 関数的完全性

真理値表は、命題変数の真理値の組み合わせごとに T か F を対応させたものである。前節の手順により、どのような真理値表に対しても、それを真理値表に持つ論理式を \(\neg\)、\(\land\)、\(\lor\) だけを使って作れる。このように、任意の真理値表を表せる論理演算の組を関数的完全であるという。

\(\{\neg, \land, \lor\}\) は関数的完全である。さらに、ド・モルガンの法則と二重否定により \(P \lor Q \equiv \neg (\neg P \land \neg Q)\) なので、\(\lor\) は \(\neg\) と \(\land\) で表せる。したがって \(\{\neg, \land\}\) だけでも関数的完全である。

論理積の否定 \(\neg (P \land Q)\) を NAND といい、\(P \uparrow Q\) と書く。NAND だけでも関数的完全である。実際、

\[\begin{split}\neg P &\equiv P \uparrow P \\ P \land Q &\equiv (P \uparrow Q) \uparrow (P \uparrow Q)\end{split}\]

が成り立つので、\(\neg\) と \(\land\) を NAND だけで表せる。デジタル回路が NAND ゲートだけで構成できるのは、この性質による。
