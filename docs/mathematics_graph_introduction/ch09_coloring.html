第 9 章 グラフ彩色

大学の期末試験の日程を組むとき、同じ学生が受ける 2 つの科目は同じ時間帯に置けない。科目を頂点とし、共通の受験者がいる科目同士を辺で結ぶと、「隣接する頂点に異なる時間帯を割り当てる」問題になる。時間帯を色とみなせば、これはグラフの頂点を色分けする問題である。本章では、このグラフ彩色の理論とアルゴリズムを学ぶ。

頂点彩色と彩色数

定義 9.1（彩色・彩色数）

グラフ \(G\) の各頂点に色を 1 つずつ割り当て、隣接する頂点が異なる色になるようにしたものを \(G\) の彩色（正確には頂点彩色）という。\(k\) 色以下で彩色できるとき \(G\) は k-彩色可能であるという。\(G\) を彩色するのに必要な色の最小数を \(G\) の彩色数といい、\(\chi(G)\) と書く。

色は 1, 2, …… や 0, 1, …… の番号で表すことが多い。同じ色の頂点の集合は、どの 2 頂点も隣接しないので独立集合（第 5 章）である。つまり \(k\)-彩色とは、頂点集合を \(k\) 個の独立集合に分割することである。

いくつかのグラフの彩色数はすぐに分かる。

  • 完全グラフ：\(\chi(K_n) = n\)。すべての頂点が互いに隣接しているからである。

  • 二部グラフ：辺を 1 本以上持てば \(\chi(G) = 2\)。定義から 2 色で塗れる。逆に 2 色で塗れれば二部グラフである。

  • 閉路グラフ：\(n\) が偶数なら \(\chi(C_n) = 2\)、奇数なら \(\chi(C_n) = 3\)。奇数長の閉路は二部グラフでない（定理 5.1）。

  • 木：頂点が 2 個以上あれば \(\chi = 2\)。木は二部グラフである。

彩色数の下界と上界

彩色数を正確に求めるのは一般に難しいが、上下から評価することはできる。

下界：\(G\) の最大のクリーク（完全部分グラフ）の頂点数をクリーク数 \(\omega(G)\)、最大の独立集合の大きさを独立数 \(\alpha(G)\) という。クリークの頂点はすべて異なる色が必要なので \(\chi(G) \ge \omega(G)\) である。また、各色の頂点は独立集合で高々 \(\alpha(G)\) 個なので、\(\chi(G) \ge n / \alpha(G)\) である。

ただし、\(\chi(G)\) は \(\omega(G)\) よりずっと大きくなりうる。三角形を含まない（\(\omega = 2\)）のに彩色数がいくらでも大きいグラフが存在することが知られている。ピーターセングラフは三角形を含まないが、5-閉路を含むので 2 色では塗れない。

上界：次の貪欲彩色の議論から、\(\chi(G) \le \Delta(G) + 1\) が成り立つ。

定理 9.1

任意のグラフ \(G\) について、\(\chi(G) \le \Delta(G) + 1\) である。

証明：頂点を任意の順に 1 つずつ塗る。各頂点を塗るとき、すでに塗られた隣接頂点は高々 \(\Delta(G)\) 個なので、それらが使っていない色が \(\Delta(G) + 1\) 色の中に必ず残っている。□

連結グラフでこの上界が等号になるのは、完全グラフと奇数長の閉路の場合だけであることが知られている。

定理 9.2（ブルックスの定理）

連結グラフ \(G\) が完全グラフでも奇数長の閉路でもなければ、\(\chi(G) \le \Delta(G)\) である。

たとえばピーターセングラフは \(\Delta = 3\) で完全グラフでも閉路でもないので、ブルックスの定理から \(\chi \le 3\) が分かる。5-閉路を含むことと合わせて \(\chi = 3\) が確定する。

貪欲彩色

定理 9.1 の証明で使った方法を貪欲彩色という。頂点を決まった順に調べ、隣接頂点が使っていない最小番号の色を割り当てる（サンプルコード coloring.py）。

リスト 14 貪欲彩色
 1def greedy_coloring(adj: AdjList, order: list[int]) -> dict[int, int]:
 2    """与えられた順に、隣接頂点が使っていない最小の色 (0, 1, 2, ...) を割り当てる。"""
 3    color: dict[int, int] = {}
 4    for v in order:
 5        used = {color[u] for u in adj[v] if u in color}
 6        c = 0
 7        while c in used:
 8            c += 1
 9        color[v] = c
10    return color

貪欲彩色は \(O(n + m)\) 時間で動作するが、使う色の数は頂点の順序に大きく依存する。図 18 の王冠グラフは、上段の頂点 \(a_i\) と下段の頂点 \(b_j\) を \(i \ne j\) のときに結んだ二部グラフであり、2 色で塗れる。ところが \(a_1, b_1, a_2, b_2, \ldots\) の順に貪欲彩色を行うと、\(a_i\) と \(b_i\) はどちらも色 \(i\) で塗られ、全部で \(n\) 色を使ってしまう。

1王冠グラフ (悪い順序): 4 色
2王冠グラフ (良い順序): 2 色

一方、上段をすべて塗ってから下段を塗れば 2 色で済む。実は、どんなグラフにも「その順序で貪欲彩色すると \(\chi(G)\) 色で塗れる」順序が存在する（最適な彩色で色 1 の頂点、色 2 の頂点、…… の順に並べればよい）。しかし、その順序を見つけることは彩色数を求めることと同じくらい難しい。

実用上は、次数の大きい頂点ほど制約が厳しいので先に塗るウェルシュ・パウエル法（largest first）などの経験的な順序がよく使われる。NetworkX の nx.greedy_color では、strategy 引数で順序の決め方を選べる。

彩色数の計算

グラフが 3 色で彩色可能かを判定する問題は NP 完全であることが知られている。したがって、彩色数を求める効率的なアルゴリズムは期待できない。小さなグラフなら、\(k = 1, 2, \ldots\) について \(k\) 色で塗れるかをバックトラックで調べればよい。

リスト 15 バックトラックによる k-彩色可能性の判定
 1def is_colorable(adj: AdjList, k: int) -> bool:
 2    """k 色で彩色できるかをバックトラックで判定する。"""
 3    order = sorted(adj, key=lambda v: -len(adj[v]))  # 次数の大きい頂点から決める
 4    color: dict[int, int] = {}
 5
 6    def assign(i: int) -> bool:
 7        if i == len(order):
 8            return True
 9        v = order[i]
10        used = {color[u] for u in adj[v] if u in color}
11        for c in range(k):
12            if c not in used:
13                color[v] = c
14                if assign(i + 1):
15                    return True
16                del color[v]
17        return False
18
19    return assign(0)

ピーターセングラフに適用すると、彩色数が 3 であることが確かめられる。

1ピーターセングラフの彩色数: 3
2NetworkX の貪欲彩色 (largest_first): 3 色

平面的グラフの彩色と四色定理

地図の国々を、国境を接する国が異なる色になるように塗り分ける問題を考える。国を頂点とし、国境を接する国同士を辺で結ぶと、平面的グラフの彩色問題になる（このグラフは第 8 章の双対グラフにあたる）。「どんな地図も 4 色で塗り分けられるか」という問いは 1852 年に提起され、長く未解決であった。

定理 9.3（四色定理）

任意の平面的グラフは 4-彩色可能である。

四色定理は 1976 年にアッペルとハーケンによって証明された。証明は、約 2000 個の「避けられない配置」の一つ一つについて、それを含む最小の反例が存在しないことをコンピュータで検証するものであり、コンピュータを本質的に用いた初めての大定理の証明として議論を呼んだ。現在では、より整理された証明が知られており、定理証明支援系 Coq による形式的な検証も行われている。

4 色の証明は難しいが、6 色なら簡単に示せる。

定理 9.4（六色定理）

任意の平面的グラフは 6-彩色可能である。

証明：頂点数に関する帰納法で示す。頂点数が 6 以下なら明らかである。平面的グラフ \(G\) には次数 5 以下の頂点 \(v\) が存在する（第 8 章）。\(G - v\) も平面的なので、帰納法の仮定により 6 色で塗れる。\(v\) の隣接頂点は高々 5 個なので、それらが使っていない色が 6 色の中に残っており、それで \(v\) を塗ればよい。□

この議論をもう少し工夫すると五色定理が証明できるが、ここでは省略する。

辺彩色

辺に色を割り当て、端点を共有する 2 辺が異なる色になるようにしたものを辺彩色という。必要な色の最小数を辺彩色数といい、\(\chi'(G)\) と書く。辺彩色は、線グラフ \(L(G)\) の頂点彩色と同じである（第 5 章）。

1 つの頂点に接続する辺はすべて異なる色が必要なので、\(\chi'(G) \ge \Delta(G)\) である。頂点彩色とは異なり、辺彩色数はほぼ \(\Delta(G)\) で決まる。

定理 9.5（ヴィジングの定理）

任意の単純グラフ \(G\) について、\(\Delta(G) \le \chi'(G) \le \Delta(G) + 1\) である。

さらに、二部グラフでは \(\chi'(G) = \Delta(G)\) が成り立つ（ケーニッヒの辺彩色定理）。それでも、一般のグラフで \(\chi'(G)\) が \(\Delta(G)\) と \(\Delta(G) + 1\) のどちらであるかを判定する問題は NP 完全である。

辺彩色の典型的な応用は、総当たり戦の日程作成である。\(n\) チームの総当たり戦は完全グラフ \(K_n\) の辺（試合）で表され、同じ色の辺は 1 チームが 1 日に 1 試合しかしない「同じ日に行える試合」になる。\(n\) が偶数なら \(\chi'(K_n) = n - 1\) なので、\(n - 1\) 日で全試合を終えられる。

彩色多項式

グラフ \(G\) を \(k\) 色以下で彩色する方法の数を \(P(G, k)\) と書く。たとえば完全グラフでは、1 つ目の頂点に \(k\) 通り、2 つ目に \(k - 1\) 通り、…… と塗れるので、次のようになる。

\[P(K_n, k) = k(k-1)(k-2) \cdots (k-n+1)\]

\(n\) 頂点の木では、根を \(k\) 通りに塗った後、各頂点を親と異なる \(k - 1\) 通りに塗れるので、\(P(T, k) = k(k-1)^{n-1}\) である。

一般のグラフでは、次の削除縮約公式が成り立つ。辺 \(e = uv\) について、\(G - e\) は \(e\) を削除したグラフ、\(G / e\) は \(e\) を縮約した（\(u\) と \(v\) を 1 つの頂点にまとめた）グラフである。

\[P(G, k) = P(G - e, k) - P(G / e, k)\]

\(G - e\) の彩色は、\(u\) と \(v\) が異なる色の彩色（これが \(G\) の彩色）と、同じ色の彩色（これは \(G / e\) の彩色と 1 対 1 に対応する）に分けられることから分かる。この公式を辺がなくなるまで繰り返し適用すると、\(P(G, k)\) は \(k\) の多項式であることが分かる。これを彩色多項式という。彩色数は \(P(G, k) > 0\) となる最小の正整数 \(k\) である。

リスト 16 削除縮約公式による彩色多項式の計算
 1def chromatic_polynomial(edges: frozenset[frozenset[int]], n: int) -> list[int]:
 2    """削除縮約公式 P(G) = P(G - e) - P(G / e) で彩色多項式の係数を求める。
 3
 4    戻り値の i 番目の要素が k^i の係数である。辺を持たない n 頂点のグラフは k^n。
 5    """
 6    if not edges:
 7        return [0] * n + [1]
 8    e = next(iter(edges))
 9    u, v = sorted(e)
10    deleted = edges - {e}
11    # 縮約: v を u に併合する。生じる自己ループは e 自身なので除かれ、多重辺は集合なので 1 本になる
12    contracted = frozenset(frozenset(u if x == v else x for x in f) for f in deleted)
13    p1 = chromatic_polynomial(deleted, n)
14    p2 = chromatic_polynomial(contracted, n - 1)
15    return [a - (p2[i] if i < len(p2) else 0) for i, a in enumerate(p1)]

1C4 の彩色多項式: k^4 - 4k^3 + 6k^2 - 3k
2K4 の彩色多項式: k^4 - 6k^3 + 11k^2 - 6k

\(C_4\) の結果は \((k-1)^4 + (k-1)\) に等しく、\(K_4\) の結果は \(k(k-1)(k-2)(k-3)\) に等しい。\(k = 2\) を代入すると、\(C_4\) は 2 通り、\(K_4\) は 0 通りとなり、彩色数がそれぞれ 2 と 4 であることと合っている。削除縮約公式は辺の数に関して指数時間かかるので、大きなグラフには使えない。

コンパイラのレジスタ割り当てでは、同時に値を保持する必要がある変数同士を結んだ干渉グラフを作り、レジスタの数を色の数として彩色する。彩色できない場合は、一部の変数をメモリに退避させる。

まとめ

  • 頂点彩色は頂点集合を独立集合に分割することであり、必要な色の最小数を彩色数 \(\chi(G)\) という。

  • \(\omega(G) \le \chi(G) \le \Delta(G) + 1\) が成り立ち、ブルックスの定理により完全グラフと奇数長の閉路を除けば \(\chi(G) \le \Delta(G)\) である。

  • 貪欲彩色は高速だが、結果は頂点の順序に依存する。彩色数を正確に求める問題は NP 困難である。

  • 平面的グラフは 4 色で彩色できる（四色定理）。6 色で十分であることは簡単に証明できる。

  • 辺彩色数は \(\Delta(G)\) または \(\Delta(G) + 1\) である（ヴィジングの定理）。

  • 彩色の方法の数は彩色多項式で表され、削除縮約公式で計算できる。
