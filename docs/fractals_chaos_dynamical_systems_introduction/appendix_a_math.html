付録 A 数学の補足

本文で使った数学のうち、高校数学の範囲を少し超えるものを簡単にまとめる。

複素数

複素数 \(z = x + iy\)（\(i^2 = -1\)）は、平面上の点 \((x, y)\) と同一視できる。この平面を複素平面といい、\(x\) を実部（\(\mathrm{Re}\,z\)）、\(y\) を虚部（\(\mathrm{Im}\,z\)）という。

極形式

原点からの距離 \(|z| = \sqrt{x^2 + y^2}\) を絶対値、正の実軸から反時計回りに測った角度 \(\theta = \arg z\) を偏角という。オイラーの公式 \(e^{i\theta} = \cos\theta + i\sin\theta\) を使うと、

\[z = |z|\,(\cos\theta + i\sin\theta) = |z|\,e^{i\theta}\]

と書ける。これを極形式という。

積と回転

2 つの複素数 \(z_1 = r_1 e^{i\theta_1}\)、\(z_2 = r_2 e^{i\theta_2}\) の積は

\[z_1 z_2 = r_1 r_2\,e^{i(\theta_1 + \theta_2)}\]

である。つまり、積は「絶対値を掛け、偏角を足す」操作である。特に、絶対値 1 の複素数 \(e^{i\alpha}\) を掛けると、原点の周りに角度 \(\alpha\) だけ回転する。第 7 章のコッホ曲線では、\(e^{i\pi/3}\) を掛けて 60 度回転させた。また、\(z^2 = r^2 e^{2i\theta}\) なので、2 乗は絶対値を 2 乗し、偏角を 2 倍する（第 9 章）。

共役複素数

\(z = x + iy\) に対して \(\bar{z} = x - iy\) を共役複素数という。複素平面では、実軸に関して折り返した点である。\(z\bar{z} = |z|^2\) が成り立つ。

Python では、1 + 2j のように j を付けて複素数を書く。abs(z) で絶対値、cmath.phase(z)（NumPy では np.angle(z)）で偏角、z.conjugate()（NumPy では np.conj(z)）で共役複素数が求められる。

2 次の行列の固有値

正方行列 \(A\) とゼロでないベクトル \(\boldsymbol{v}\) が \(A\boldsymbol{v} = \lambda\boldsymbol{v}\) を満たすとき、数 \(\lambda\) を \(A\) の固有値、\(\boldsymbol{v}\) を固有ベクトルという。固有ベクトルの方向では、\(A\) を掛ける操作は、\(\lambda\) 倍に伸び縮みさせるだけになる。

2 次の行列 \(A = \begin{pmatrix} a & b \\ c & d \end{pmatrix}\) の固有値は、2 次方程式

\[\lambda^2 - (a + d)\,\lambda + (ad - bc) = 0\]

の解である。\(\tau = a + d\) をトレース、\(\Delta = ad - bc\) を行列式という。解の公式から、固有値は

\[\lambda = \frac{\tau \pm \sqrt{\tau^2 - 4\Delta}}{2}\]

となる。\(\tau^2 - 4\Delta < 0\) のとき、固有値は互いに共役な複素数になる。2 つの固有値の和は \(\tau\)、積は \(\Delta\) に等しい。

第 3 章の平衡点の分類は、トレースと行列式で次のように言い換えられる。

\(\Delta < 0\)

中心

NumPy では、np.linalg.eigvals(A) で固有値を、np.linalg.eig(A) で固有値と固有ベクトルを求められる。

テイラー展開と線形化

関数 \(f\) が点 \(a\) の近くで滑らかなら、

\[f(x) = f(a) + f'(a)(x - a) + \frac{f''(a)}{2}(x - a)^2 + \cdots\]

と、\(x - a\) のべき乗の和で表せる。これをテイラー展開という。\(x\) が \(a\) に十分近ければ、\((x - a)^2\) 以降の項は \((x - a)\) の項に比べて非常に小さいので、

\[f(x) \approx f(a) + f'(a)(x - a)\]

と 1 次式で近似できる。これが第 2 章の線形化である。

多変数の関数 \(F(\boldsymbol{x}) = (F_1(\boldsymbol{x}), \ldots, F_n(\boldsymbol{x}))\) では、微分 \(f'(a)\) の代わりに、偏微分を並べたヤコビ行列 \(J_{ij} = \partial F_i / \partial x_j\) を使う。

\[F(\boldsymbol{x}) \approx F(\boldsymbol{a}) + J(\boldsymbol{a})(\boldsymbol{x} - \boldsymbol{a})\]

第 3 章では、この近似を使って、非線形の系の平衡点を線形の系として調べた。また、ヤコビ行列の行列式の絶対値は、写像によって小さな領域の面積（体積）が何倍になるかを表す（第 6 章）。

べき乗則と両対数グラフ

2 つの量の間に \(y = C x^{a}\) の関係（べき乗則、power law）があるとき、両辺の対数をとると

\[\log y = a \log x + \log C\]

となり、\(\log x\) と \(\log y\) は直線の関係になる。したがって、両対数グラフに点を描いて直線になれば、べき乗則が成り立っていると判断でき、直線の傾きが指数 \(a\) を表す。第 3 章の数値解法の誤差、第 7 章のボックスカウント次元、第 10 章の相関次元は、いずれもこの方法で指数を求めた。

一方、\(y = C e^{a x}\) の関係（指数関数的な変化）は、縦軸だけを対数目盛りにした片対数グラフで直線になる。第 5 章の初期値鋭敏性では、差の時間変化が片対数グラフで直線になることから、差が指数関数的に増えることを確かめた。

直線の傾きは、最小二乗法で求められる。NumPy では、np.polyfit(np.log(x), np.log(y), 1) で、傾きと切片が得られる。
