確率論・離散数学入門

本書は、Python の知識があるエンジニアや工学系の大学生を対象とした、離散数学と確率論の入門書である。集合・論理・数え上げ・グラフといった離散数学の基礎から始め、有限または可算個の値をとる確率（離散確率）を学び、最後にアルゴリズムへの応用を扱う。定義や定理は数式で述べ、その内容を Python のサンプルコードで確かめながら読み進められるように構成している。
